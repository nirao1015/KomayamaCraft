# 地形エフェクト Unity制御メモ

実装状況・確定パラメータは  
`spec/KomayamaCraft_地図演出コントローラー_詳細仕様.md` を正とする。  
（雲影・胞子雲は実装済み。下記の数値は未実装種の見た目指針／参考。）

## 雲影
- SpriteRendererの色アルファを0→0.20～0.35→0へ変化。
- 指定方向へ12～25秒かけて等速移動。次回発生まで6～20秒のランダム待機。
- 4画像からランダム選択し、速度と開始Y座標を少し変える。

## 西海岸の白波
- 左側の海から右側の砂浜へ0.8～1.5秒移動。
- 前半は画像本来のアルファを維持し、後半40%で全体をフェードアウト。
- 4画像からランダム選択。同じ位置で連続させず、海岸線上のY座標をずらす。

## 海上の風筋
- フェードインしながら左→右へ移動し、寿命後半でフェードアウトする方式を推奨。
- 1.5～3秒、移動距離は画像幅の0.5～1.0倍。出現間隔4～12秒。
- 加速は付けず、一定速度の方が海上の広い風に見える。

## 胞子雲
- 常設オブジェクトとして8～14秒周期でアルファ0.15～0.45を往復。
- 周期ごとに座標を画面幅の1～3%だけずらす。急な移動はさせない。

## 気泡
- 4画像からランダム選択し、0.6～1.2秒で少し上昇して消す。
- 同時表示は1～3個まで。

## 浮石
- 個体ごとに1～4px上下移動。周期1.8～4.5秒、開始位相をランダム化。
- 8種類を回転させず使うと、光源方向を維持できる。

## 小型熱嚢草・小型軌道繭
- 基本は静止配置。必要ならスケールを98～102%でゆっくり往復。
- 元の採集施設の近くへ密集させず、背景として疎らに配置。

## 砂埃
- 左→右へ2～5秒移動。開始0.3秒でフェードイン、終了0.8秒でフェードアウト。
- 高さ、速度、4画像の選択をランダム化。同時表示は最大2本程度。

## 間欠泉
- 5コマを単発再生。推奨フレーム時間: 0.12 / 0.10 / 0.08 / 0.08 / 0.18秒。
- 最終フレーム後は即座に非表示。ランダム待機4～15秒。

## 位相断層の緑色雷
- 4コマを単発再生。推奨フレーム時間: 0.10 / 0.07 / 0.09 / 0.16秒。
- 発生前後は非表示。ランダム待機3～12秒。Bloomは強い第3フレームを中心に適用。
