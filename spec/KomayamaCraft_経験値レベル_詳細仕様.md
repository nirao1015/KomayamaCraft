# KomayamaCraft 経験値・レベル・スキルポイント 詳細仕様

## 0. 文書の位置づけ

- 要素設計書 §10（経験値・スキル・装備）の成長のうち、**経験値・レベル・スキルポイント獲得**を具体化する。
- スキルツリーへの投資内容・各スキル効果は別文書（本書はポイントの増減と表示まで）。
- HUD 見た目（バー素材・配置）は `MenuRoot/Top/Oj経験値バー` および `UI_Exp` 分割（Frame / Bg / Fill）。文言は `TextLv` / `TextExp` / `TextSkill`。
- 値の書き方：**確定**／**提案**／**現行値**。
- **旧セーブ互換は行わない**（進行データの意味が変わるため、ロード時に新規則で読み直す／初期化する。版上げで切ってよい）。

## 1. 用語

| 用語 | 意味 | 区分 |
| --- | --- | --- |
| 累積経験値 | セーブする経験値。生涯獲得の合計（レベル内リセットなし） | 確定 |
| 累積閾値 | 「そのレベルに到達するために必要な累積経験値」 | 確定 |
| レベル | 0〜99。初期 0。上限 99 | 確定 |
| スキルポイント（SP） | スキル取得に使う。初期 0。上限 **999**（オーバーフロー防止キャップ） | 確定 |

## 2. レベルと経験値テーブル

### 2.1 テーブル形式（確定）

- **累積閾値テーブル**を別データ（ScriptableObject / CSV 等）で持つ。
- エントリ例の意味：`threshold[L]` ＝ **レベル L に到達するために必要な累積経験値**。
- `threshold[0] = 0`（初期）。
- レベルを 1 上げるには累積経験値が `threshold[level+1]` 以上必要。
- 表示例：閾値が Lv1=10、Lv2=30 のとき、ちょうど Lv1 到達直後は **`[10/30]`**（現在累積 / 次レベル累積閾値）。

| レベル | 累積閾値（例・数値は仮） | 備考 |
| --- | --- | --- |
| 0 | 0 | 初期 |
| 1 | 10 | 例 |
| 2 | 30 | 例 |
| … | … | テーブルで定義 |
| 99 | （最終閾値） | 到達後は §2.3 |

実数値はテーブル資産で調整する（本書は形式のみ確定）。

### 2.2 レベルアップ処理（確定）

1. 経験値を加算する（§3）。
2. `level < 99` かつ `experience >= threshold[level+1]` のあいだ繰り返す：
   - `level++`
   - SP を **+1**（§4。キャップ適用）
3. 一度の加算で複数閾値を超えた場合は **まとめて複数レベル＆複数 SP** を付与する。

### 2.3 レベル 99 到達後（確定）

- 累積経験値は **最終閾値（Lv99 到達に必要な値）で打ち止め**。それ以上は加算しない。
- 表示：`[最終閾値/最終閾値]`、経験値バーは **常時 100%**。
- レベルは 99 のまま。これ以上の LvUp・SP（レベル経由）は発生しない。

## 3. 経験値の獲得

### 3.1 獲得源（確定）

| 源 | 付与タイミング | 備考 |
| --- | --- | --- |
| 採集 | 採集が成立したとき | 行動別テーブルで量を定義 |
| 物品生産完了 | **施設の加工が正常完了したとき** | 下記 §3.2 |
| クエスト完了 | **完了報告時のみ** | 受注時・進行中は付与しない。クエスト別テーブル |

手持ちクラフトは存在しない前提。経験値量は **行動・レシピ・クエスト別テーブル**（固定一律ではない）。

### 3.2 施設加工と無効条件（確定）

| 状況 | EXP |
| --- | --- |
| 施設がレシピ加工を **完了**（完成品を出す処理まで到達） | レシピ別テーブルの量を付与 |
| 生産中にプレイヤーが完成品を「取り出す」操作で中断する想定 | **本仕様では完成前取り出しは想定しない**／完了前に無効化する破壊等は付与しない |
| 生産中に施設を壊した・撤去した | **付与しない**（無効） |
| 投入だけして未完了 | **付与しない** |

完了の定義は `spec/KomayamaCraft_施設加工操作_詳細仕様.md` の「完了」（完成品ドロップ等）に従う。完了コールバックでのみ EXP を渡す。

### 3.3 テーブル資産（提案・実装時に確定）

| テーブル | キー例 | 値 |
| --- | --- | --- |
| 採集 EXP | 資源ノード／アイテム定義 ID | 付与量 |
| 生産 EXP | レシピ ID | 付与量 |
| クエスト EXP | クエスト ID | 付与量（完了報告時） |
| レベル閾値 | レベル 0〜99 | 累積経験値 |

未定義キーは 0（付与なし）またはログ警告＋0。方針は実装時に一本化する。

## 4. スキルポイント

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 初期 | 0 | 確定 |
| 上限 | 999 | 確定 |
| レベルアップ | 1 レベルにつき **+1**（複数 Lv ならその回数分） | 確定 |
| レベル以外 | 隠し要素クリア等で **明示的に別途付与**。そのときは LvUp とは別に「スキルポイント入手」をプレイヤーへ通知（プッシュ）する | 確定（中身の一覧は後続） |
| 消費 | スキル取得時に減算（スキル詳細は別文書） | 確定 |

レベル以外付与の具体リストは枠のみ確保し、個別コンテンツ定義時に追記する。

## 5. HUD 表示

### 5.1 文言（確定）

| オブジェクト | 表示形 | 例 |
| --- | --- | --- |
| `TextLv` | `レベル {n}` | `レベル 0` |
| `TextExp` | `[{current}/{next}]` | `[10/30]` |
| `TextSkill` | `スキルポイント {n}` | `スキルポイント 0` |

- `{current}`＝累積経験値（打ち止め後は最終閾値）。
- `{next}`＝次レベル累積閾値。Lv99 では `{next} = {current} = 最終閾値`。

### 5.2 経験値バー（確定）

- Fill 割合＝レベル内進捗：
  - `prev = threshold[level]`
  - `next = threshold[level+1]`（Lv99 では `next = prev = 最終` → **常時 1.0**）
  - `fill = (experience - prev) / (next - prev)`（分母 0 なら 1）
- 素材：`UI_Exp_Frame` / `UI_Exp_Bg` / `UI_Exp_Fill`（Fill は Horizontal Filled）。
- ルート位置は Inspector（`Oj経験値バー`）。コードが位置を上書きしない。

## 6. 演出・フィードバック

| 契機 | 内容 | 区分 |
| --- | --- | --- |
| レベルアップ | **SE**（回数が多いため紙吹雪等の大きな演出は基本しない） | 確定（SE 種類は実装時） |

## 7. セーブ

| フィールド | 意味 | 区分 |
| --- | --- | --- |
| `progress.experience` | 累積経験値（0〜最終閾値） | 確定 |

## 8. 受け入れ条件

- [ ] 新規ゲームは Lv0・EXP0・SP0。
- [ ] 採集／施設加工完了／クエスト完了報告でのみ EXP が増える（量は各テーブル）。
- [ ] 生産中破壊・未完了では EXP が増えない。
- [ ] 累積表示が `[current/nextThreshold]`。LvUp 直後の例が `[10/30]` 型になる。
- [ ] 一気に閾値を超えると複数 Lv＋同数 SP。
- [ ] Lv99 で EXP 打ち止め・表示 `xxx/xxx`・バー 100%。
- [ ] SP は 999 で頭打ち。別途付与時は専用通知。
- [ ] HUD 文言が §5.1 どおり。
- [ ] LvUp は SE（大きな紙吹雪演出なしが既定）。
