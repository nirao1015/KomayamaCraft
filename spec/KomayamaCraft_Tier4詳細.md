# Tier 4 詳細仕様

M8実装の正本。生素材1、設備1、最終部品1の短いラインとする。

## 地域

- `tier4`：慣性相殺環を船へ入れたあと解放する。
- 軌道繭だけを置く。

## 定義

| 種類 | 永続ID | 表示名 |
| --- | --- | --- |
| 発生点 | `resource_node.orbit_cocoon` | 軌道繭 |
| 素材 | `item.orbit_silk` | 軌道絹 |
| 設備 | `facility.vacuum_spinner` | 真空紡績機 |
| レシピ | `recipe.interstellar_compass` | 恒星間羅針紡績 |
| 最終部品 | `item.interstellar_compass` | 恒星間羅針 |
| 解放 | `unlock.tier4_inertia_ring` | 離陸準備完了 |

## 接続

- 軌道絹は軌道繭から即時再生採集する。待ち時間なし。
- 真空紡績機の建設費は位相継手2（Tier 3中間品）。
- レシピ入力：軌道絹1、慣性相殺環は消費しない。補強フレーム1と熱嚢セル1を燃料兼材料とする。
  - 入力：軌道絹1、補強フレーム1
  - 燃料：熱嚢セル
  - 出力：恒星間羅針1
- 恒星間羅針を船スロット`compass`へ入れると脱出可能になる。
- 脱出は確認のうえ開始できる。未取り付けでは開始できない。
- クリア後はフィールドへ戻り、再脱出できる。
