# logo_view
-[]でくくったものはUNITY内の GameObject である
- <>でくくったものは Inspector変数 である

## 画面構成
- 背景画像[背景画像]を表示
- 画面中央に画像[企業ロゴ画像]を配置

## 挙動
- シーン開始時 画面構成 のオブジェクトを表示

## [game_manager]での挙動制御
- <メニューへ遷移する秒数>で指定した秒数経過後、1秒かけて画面全体を真っ黒へトランジションさせる
- menuシーンへ遷移

## Inspector変数定義 [game_manager]
- Header：企業ロゴトランジション設定
* <メニューへ遷移する秒数>の詳細
 * Int デフォルト：3
 * Tooltip：メニューへ遷移する秒数
