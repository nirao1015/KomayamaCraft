# 開発用 Steam スクショ（メインカメラのみ）

## 1. 目的

- Steam ストア用など、**ワールド表示（メインカメラ）だけ**を高解像度 PNG で保存する。
- **エディタ再生中のみ**利用する。製品ビルドには含めない。
- **キーボードショートカットは使わない**。Unity の Shortcut Manager や OS のホットキーと競合させない。
- **全シーン共通**：シーンごとのプレハブやコンポーネント追加は不要。エディタメニューから実行する。

## 2. スコープ

### 2.1 対象カメラ

- **`Camera.main`**（シーン内で有効かつ `MainCamera` タグが付いたカメラのうち、Unity が返す 1 台）のみを描画対象とする。
- メインカメラ以外のカメラ（オーバーレイ用 UI カメラなど）は **合成しない**。オーバーレイや別カメラ経由の UI は **画像に含まれない**（メインカメラのビューだけになる）。
- **Screen Space - Overlay** の Canvas はメインカメラに描画されないため、**スクショには載らない**。

### 2.2 解像度

- メニュー項目 **`Steam用スクショ（メインカメラ） 2x`** は、ゲームビュー上でのメインカメラの描画ピクセル領域（`pixelWidth` × `pixelHeight`）の **長辺・短辺ともに 2 倍**の解像度で出力する（Unity の `ScreenCapture.CaptureScreenshot(..., 2)` と同様の「スーパーサイズ」概念。実装はメインカメラ専用レンダー）。
- ビューポート矩形（`camera.rect`）がフルスクリーンでない場合も、`pixelWidth` / `pixelHeight` に合わせる。

### 2.3 実行条件

- **`Application.isPlaying` が true** のときのみメニューを実行可能とする（バリデーションで無効化）。
- **`Camera.main` が null** のときも実行不可とする。
- ユーザーは **ポーズでゲームを止めた状態**でメニューから保存してよい（入力や時間経過は不要）。

### 2.4 保存先・ファイル名

- プロジェクトのルート（`Assets` のひとつ上のディレクトリ）直下に **`Screenshots/SteamDevMainCamera/`** を作成し、その中に保存する。
- ファイル名: `maincamera_<シーン名>_<yyyyMMdd-HHmmss>_2x.png`（例: `maincamera_game02_scene_20260506-143052_2x.png`）。
- 保存完了後、コンソールに **フルパス**を `Debug.Log` で出力する。

## 3. 非スコープ（今回やらない）

- 製品ビルドや Development Player での実行。
- キーバインド・ゲーム内 UI からのトリガー。
- メインカメラ以外を選択する UI（常に `Camera.main` のみ）。
- 動画キャプチャ。

## 4. 実装方針

- コードは **`Assets/Editor/`** に Editor 専用スクリプトとして置き、**ビルド成果物に載らない**ようにする。
- URP 環境では、メインカメラに一時的に `RenderTexture` を割り当て、`Camera.Render()` で 1 フレーム描画した結果を `Texture2D.ReadPixels` → `EncodeToPNG` で書き出す。
- 処理後は **`targetTexture` を必ず元に戻す**（漏れるとゲームビューが真っ黒になるなどの不具合になるため）。

## 5. メニュー

| メニュー | 説明 |
|---------|------|
| `ツール/開発用/Steam用スクショ（メインカメラ） 2x` | 上記条件で PNG を保存する。 |

（再生中かつ `Camera.main` が存在するときのみ有効。）
