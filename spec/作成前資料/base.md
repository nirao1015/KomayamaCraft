# 画面基本設定

## 1. 基準解像度・基準アスペクト比

- 本プロジェクトの基準解像度は **1920x1080** とする。
- 基準アスペクト比は **16:9（1920:1080）** とする。
- ゲームの主要描画領域（以下「ゲーム画面」）は、端末ごとにアスペクト比を変形しない。

## 2. 表示方針（アスペクト比固定＋余白描画）

- 端末解像度が 16:9 と一致しない場合でも、**ゲーム画面は常に 16:9 を維持**する。
- 16:9 との差分領域は「余白領域」として扱い、以下の方針で描画する。
  - 端末が 16:9 より横長（例: 21:9）: **左右に余白**を表示（ピラーボックス）。
  - 端末が 16:9 より縦寄り（例: 4:3）: **上下に余白**を表示（レターボックス）。
- 余白領域は黒帯固定ではなく、プロジェクトの演出方針に合わせて
  **背景色・背景画像・パターン等を描画可能**とする。

## 3. 対応レンジ

- 対応対象の想定アスペクト比レンジ:
  - **最小（横長側）: 21:9**
  - **最大（縦寄り側）: 4:3**
- 上記レンジ内では、ゲーム画面が欠けたり伸縮したりしないことを必須とする。

## 4. Unity実装方針（要件）

- カメラ表示は 16:9 を維持できる方式で制御する（例: `Viewport Rect` 調整）。
- UI はゲーム画面基準で崩れないようにし、余白領域に依存する UI は別レイヤーで管理する。
- レイアウト基準は 1920x1080 とし、解像度差分はスケーリングで吸収する。
- 適用は **全シーン共通**とし、シーンロード時に自動で有効化する。
  - カメラ: `FixedAspectCameraFitter`
  - Canvas: `FixedAspectCanvasFitter`
  - ブートストラップ: `AspectSettingsBootstrap`

## 5. 受け入れ条件

1. 1920x1080 で意図した見た目になること。  
2. 21:9 で左右余白、4:3 で上下余白が表示されること。  
3. いずれの比率でもゲーム画面（16:9）が変形しないこと。  
4. 余白領域に対して背景描画が適用できること。
