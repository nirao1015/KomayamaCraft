# KomayamaCraft 建設メニュー（menu建設）詳細仕様

## 0. 文書の位置づけ

- 要素設計書 §7「設計図・建設・配置変更」および基本仕様の建設フローを、`menu建設` 起点の UI／入力として具体化する。
- 個別設備の建設費・レシピ・見た目はサプライチェーン資料・設備定義が正本。本書は**操作・配置・仮組・階層**を定める。
- 値の書き方：**確定**／**提案**／**現行値**。
- **本書は確定稿**（2026-09-14 更新）。スライド時間・色味等の見た目数値は Inspector 調整可（共通設定参照）。

---

## 1. 概要

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 入口 | `MenuObject / menu建設`（右端メニューバーの建設アイコン） | 確定 |
| パネル | 画面右端からスライドインする建設リスト | 確定 |
| 役割 | アンロック済み施設の選択→配置、仮組への納品完了、編集（解体・移動） | 確定 |
| 表示名の例 | データ上 `ScaleRollingWorkbench`。表示名は **鱗圧延作業台** | 確定 |
| 配置単位 | **ピクセルではなくブロック単位**。1 ブロック＝建設不可マス 1 マスと同じ。配置時はブロックに吸い付く | 確定 |
| ブロック辺長 | `KCBuildSettings.blockSize` が正本。**0.5** ワールド単位（`NoDropPaint` セルと同寸）。`BuildRestrictionGrid.cellSize` も同じ値 | 確定 |
| 施設占有サイズ | **施設ごと**に幅・高さ（ブロック数）。共通固定ではない | 確定 |
| 鱗圧延作業台の占有 | 横 **10** × 縦 **8** ブロック → ワールド **5.0 × 4.0** | 確定 |

## 2. 開閉（menu建設）

| 操作 | 結果 | 区分 |
| --- | --- | --- |
| `menu建設` 押下（閉じている） | 建設パネルが右端から**スライドイン**して開く | 確定 |
| `menu建設` 押下（開いている） | パネルが**スライドアウト**して閉じる（トグル） | 確定 |
| 開いている状態でスキル／設定など他メニューを押す | **建設をキャンセル**（パネル閉じ＋配置／編集モード解除）し、そのメニュー画面を表示 | 確定 |

- 他メニューとの並列表示はしない（排他）。

## 3. 建設パネルの内容

### 3.1 施設リスト

| 状態 | 表示 | 操作 | 区分 |
| --- | --- | --- | --- |
| アンロック済み | 通常の枠・アイコン・名称 | クリックで配置モードへ | 確定 |
| 未解放 | **専用テキストと枠**を表示 | クリックしても**無反応** | 確定 |

### 3.2 編集モードボタン

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 位置 | リスト**一番下** | 確定 |
| 初期 | **最初から開放済み** | 確定 |
| 操作 | **トグル**（ON／OFF） | 確定 |
| 建設リストとの同時 | **不可**。リストから施設を選んだら編集は OFF。編集 ON 中に建設候補をクリックしたら、編集を OFF にして配置モードへ | 確定 |

### 3.3 設置上限

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 上限 | **100** | 確定 |
| 数え方 | `Layer_Facilities` 上の施設。**仮組を含む。Ghost を含む** | 確定 |
| 超過時 | **新規建設を選んだ時点**でエラー（配置モードに入らない） | 確定 |
| 移動 | 上限に達していても**移動は可能**（件数は増えない） | 確定 |

## 4. 配置モード

### 4.1 入り方・メニュー

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 入り方 | アンロック済み施設をクリック（本段階はリスト `Item_0`＝鱗圧延作業台） | 確定 |
| 建設パネル | 施設クリック後は**閉じる** | 確定 |
| 入力モード | `Build`（`KomayamaInputMode.Build`） | 確定 |

### 4.2 ブロック吸い付き

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 座標 | カーソル位置をブロック格子へスナップ | 確定 |
| 格子 | 建設不可マス（`NoBuildPaint`）と同一グリッド | 確定 |
| 占有 | 設備が占めるブロック矩形が、禁止マス・他設備・不可レイヤーと重なれば配置不可 | 確定 |

### 4.3 配置可否フィードバック

| 状況 | 表示 | 区分 |
| --- | --- | --- |
| 置ける位置にホバー | 半透明青／水色のブループリント（色・透明度は `KCBuildSettings` で全施設共通。Inspector 調整可） | 確定 |
| 置けない位置にホバー | **建設禁止カーソル**（仮アイコン可）＋プレビューを配置不可色へ | 確定 |
| 置けない位置でクリック | 配置しない（メッセージは既存 HUD に合わせてよい） | 提案 |

### 4.4 配置の確定と連続

| 操作 | 結果 | 区分 |
| --- | --- | --- |
| 有効位置で左クリック（Shift なし） | 仮組を 1 件設置し、**配置モード終了** | 確定 |
| 有効位置で左クリック（**Shift 押し続け**） | 同種を設置し、**配置モード継続** | 確定（本段階は未実装でよい） |
| 上限に達した直後 | 連続配置は不可。エラーして配置モード終了でよい | 提案 |

### 4.5 配置モードのキャンセル

次のいずれかで配置モードを抜け、フィールド通常操作へ戻る。仮組は作らない。

| 操作 | 区分 |
| --- | --- |
| **Escape** | 確定 |
| **右クリック** | 確定 |
| **`menu建設` 再押下** | 確定（パネルはトグル規則に従う。配置はキャンセル） |

- 空き地クリックではキャンセル**しない**（確定）。

### 4.6 配置直後の状態

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 状態 | **仮組**（未完成） | 確定 |
| 建設費の消費 | 配置時点では消費しない。**納品した分だけ**仮組に積み、必要数そろった時点で完成 | 確定 |
| 見た目 | 施設スプライトを占有矩形（横×縦）に**合わせる**（縦横比を維持せず矩形いっぱいに伸ばしてよい。仮画像可） | 確定 |
| 親 | `World / Layer_Facilities` | 確定 |

## 5. 仮組 → 完成

### 5.1 納品

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 手段 | **手持ちを仮組の施設範囲（コライダー）へ右クリック投入**。地面には置かない | 確定 |
| 表示 | 枠アイコン＋`0/5` 等は**表示のみ**。納品はアイコンクリックではない | 確定 |
| 単位 | **1 個ずつ**。例：鉄鱗 0/5 → … → 5/5 で完成。途中（2/5 など）がありうる | 確定 |
| 違う素材 | **無反応**（ビープ・メッセージなし）。地面ドロップもしない | 確定 |
| 手持ち混在 | 建設用とそれ以外を両方持っていても、**ソート順に関わらず建設用素材だけ**が入る | 確定 |
| 完成時 | 要求がすべて揃った瞬間に完成施設へ切り替わる（瞬時完了） | 確定 |
| 完成直後の長押し | **同一の右ボタン押しっぱなしでは、完成施設への生産投入を開始しない**。ボタンを離し、もう一度押すまで素材を入れない | 確定 |
| チェスト直送 | **なし**（本書スコープ外） | 確定 |

### 5.2 完成後

- 通常の完成施設として加工・保管等の機能が使える（設備種別による）。
- 仮組中は加工不可。
- 完成直後のレシピは**未選択**。左クリック・投入・生産・排出・ワールド表示は `spec/KomayamaCraft_施設加工操作_詳細仕様.md` が正本。
- 完成施設も占有矩形と同じ見た目サイズ（§4.6）。Sorting は `WorldObject`。
- 生成は `FacilityDefinition.Prefab` の **Instantiate**。親は `Layer_Facilities`。

## 6. 編集モード

### 6.1 トグル

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| ON | 設置済み（仮組含む）施設に操作アイコンを**常時**表示 | 確定 |
| OFF | アイコン非表示。通常操作に戻る | 確定 |
| 建設パネル | 編集トグル時もパネルは開いたままでよい（§3.2） | 提案 |

### 6.2 施設上のアイコン（常時）

| アイコン | 操作 | 区分 |
| --- | --- | --- |
| ゴミ箱 | 解体 | 確定 |
| 上下左右矢印 | 移動（再配置）開始 | 確定 |

### 6.3 移動

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 仮組 | **仮組のまま移動可**。納品進捗は維持 | 確定 |
| 完成 | **内部在庫・燃料・加工中状態を維持**したまま移動 | 確定 |
| スナップ | 新規配置と同じブロック吸い付き | 確定 |
| キャンセル | Escape／右クリック／`menu建設` で中止し元位置へ | 提案 |
| 上限 | 件数は増えないため 100 でも可 | 確定 |

### 6.4 解体と返却

返却は**地面ドロップ**（既存ドロップ規則に従う）。

| 対象 | 返却 | 区分 |
| --- | --- | --- |
| 仮組の建設納品分 | **納品済み分だけ**地面へ | 確定 |
| 完成の建設費（粗材） | **全額**地面へ | 確定 |
| 完成の入力スロット | **全返却** | 確定 |
| 完成の出力スロット | **全返却** | 確定 |
| **加工中**の素材 | **消滅** | 確定 |
| **燃料** | **消滅** | 確定 |
| ドロップ溢分 | **消滅**（既存ドロップ不可時と同じ） | 確定 |

| 状態 | 建設パネル | フィールド | 区分 |
| --- | --- | --- | --- |
| 通常 | 閉 | 採集・ドロップ等 | 確定 |

## 8. 配置判定・階層・見た目

### 8.1 配置判定

| 判定 | 内容 | 区分 |
| --- | --- | --- |
| 建設可能範囲 | `FieldPlacementSurface` 内 | 確定 |
| 建設不可塗り | `NoBuildPaint`／`PlacementBlocker`（ドロップ禁止とは別 Tilemap・別判定） | 確定 |
| 建設不可の見た目 | **緑色**半透明。Scene で NoDrop と同様に編集可。デバッグ時はゲーム画面にも表示（`KomayamaCraftDebugManager`） | 確定 |
| 他設備・占有 | 重なり不可 | 確定 |
| 着陸地点の荒れ地 | 建設不可として塗る（宇宙船周辺など） | 確定 |

### 8.2 ワールド階層

| オブジェクト | Sorting | 役割 | 区分 |
| --- | --- | --- | --- |
| `World / WorldLayers` | Sea〜Effect | 地形・フィールドオブジェクト | 確定（既存） |
| `World / Layer_Facilities` | `WorldFacility` | **建設物の親**。仮組・完成施設・保管等。`WorldObject`（発生点）の次・エフェクトより前 | 確定 |
| `World / Layer_Mouse` | `WorldMouse` | 手持ち・狐 | 確定（既存） |
| `World / Layer_System` | System | UI | 確定（既存） |

- `World` 直下に建設物をバラ撒かない。`KomayamaBuildController.facilityRoot` は `Layer_Facilities`。
- 完成施設：プレハブ Instantiate。仮組：実行時生成（プレハブでなくてよい）。どちらも親は `Layer_Facilities`。上限 100 を前提に軽量な生成でよい。

### 8.3 共通設定（`KCBuildSettings`）

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| `blockSize` | 0.5（正本） | 確定 |
| ブループリント配置可色 | 半透明青／水色。全施設共通。Inspector で調整 | 確定 |
| ブループリント配置不可色 | 赤み等。全施設共通 | 確定 |
| 建設禁止カーソル | テクスチャ（仮可）＋ホットスポット | 確定 |

## 12. 実装メモ

- UI：`MenuRoot` / `SystemCanvas`。スクリプト：`Assets/Scripts/komayama_craft_scene/`。
- 参照は Inspector アタッチ。実行時 `Find` / ソース足しの `AddComponent` は使わない（動的生成する仮組は除く）。
- 宇宙船着陸地点の荒れ地は `NoBuildPaint` で塗る。セルサイズ変更時は塗りとワールド位置の対応を崩さないこと。
