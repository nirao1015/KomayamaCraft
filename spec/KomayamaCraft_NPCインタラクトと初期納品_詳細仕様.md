## 2. 納品の正規操作（確定）

チュートリアルの鱗鉄板納品は **契約掲示板ではなく NPC 直納品**。

| 項目 | 内容 |
| --- | --- |
| 受け口 | NPC と同じオブジェクト（または子）の `KomayamaDepositBin` |
| 操作 | 手に対象アイテムを持ち、NPC 上で**右クリック**（既存 Deposit 経路） |
| 単位 | 1 クリック 1 個 |
| 会話 | 左クリックはヒント／案内。納品カウントは右クリック投入で進む |

自動化プレイも同じ経路のみ使う（内部カウンタ直書き禁止）。

## 3. 雨漏りクエスト：生産完了〜初期納品（確定）

クエスト ID：`main_rain_leak`（表示名はログ側）。

| 段階 | 挙動 |
| --- | --- |
| 鱗鉄板 3 枚生産完了 | カメラを DeliveryNpc 付近へ移動 → 納品依頼会話（`craft_quest_leak_ask_deliver`） |
| 納品待ち開始 | ログ詳細を納品 `0/3` 表示。NPC マーカーを納品（○）。会話キーをヒント用に差し替え可 |
| 納品中 | `DepositBin` へ鱗鉄板を投入するたびカウンタ＋1（最大 3） |
| 3／3 | 完了会話（`craft_quest_leak_deliver_done`）→ **宇宙船修理演出**（`spec/KomayamaCraft_宇宙船修理演出_詳細仕様.md`）→ 雨漏りクエスト Completed |
| 直後 | DeliveryNpc の既定会話を戻し、次クエスト（燃料補給系）受注可能の！を出す |

生産レシピ（現行）：鱗鉄板＝鉄鱗 ×2。作業台完成時にチュートリアル用燃料チャージを付与する。

## 4. 現状把握（WASD）（確定）

| 項目 | 内容 |
| --- | --- |
| クエスト | `main_situation_survey` |
| 条件 | W／A／S／D をそれぞれ必要秒以上押す（現行 **0.1** 秒×4＝合計約 **0.4** 秒） |
| 表示 | クエストログ本文にキー画像（`key_w` / `key_a` / `key_s` / `key_d` TMP Sprite）＋方向ラベル |
| 完了後 | カメラ戻し演出 → 終了会話 → 雨漏り導入へ |

雨漏り受注後のログタイトルは **`宇宙船の雨漏りを直そう`**（詳細見出し・採集行の書式は `spec/KomayamaCraft_クエストログ表示_詳細仕様.md` §4.4）。
