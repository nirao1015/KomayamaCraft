# KomayamaCraft 地図演出コントローラー 詳細仕様

> **状態**：実装済み（雲影・胞子雲・沼気泡・熱嚢草・間欠泉・砂漠砂嵐・海上風筋・西海岸白波・浮小岩／小島ゆらぎ・狐うたたね）。残りの地図エフェクトは後続実装。  
> **シーン**：`Assets/Scenes/komayama_craft_scene.unity`  
> **親**：`World/WorldLayers/Layer_Effects`（Sorting Layer `WorldEffect`）  
> **素材メモ**：`Assets/Sprites/map_effect/Unity_control_notes.md`（未実装種の見た目指針）  
> **関連**：`KomayamaGameClock`（倍速・一時停止）、描画バンド仕様

---

## 1. 目的 / 非目的

### 目的

- 雰囲気用・**スキップ可能な**地図演出を一か所で予算管理する
- ピーク負荷を抑え、ゲーム不可（スパイク）を防ぐ
- 地図チャンネルとアニメ（低優先カーソル）チャンネルを**コード分離**する

### 非目的

- 生産・納品・ダメージ・クエストなど **必須ゲーム演出**
- 狐の位置追従そのもの（入力応答は `KCMouseFoxFollower` のまま）
- 施設ワールド HUD・メニュー UI

## 3. コントローラ

### 3.1 クラス

| クラス | 役割 |
| --- | --- |
| `KomayamaMapAmbienceController` | 5 秒ティック・予算・地図／アニメリスト |
| `KomayamaMapAmbienceMapChannel` | 地図チャンネル基底 |
| `KomayamaMapAmbienceAnimChannel` | アニメチャンネル基底 |

配置：`Layer_Effects` にコンポーネントとしてアタッチ。チャンネル参照は Inspector 登録（Find しない）。

### 3.2 ループ

1. ティック間隔（既定 **5 秒**、ゲーム時間＝scaled）ごとに処理
2. 地図チャンネル → アニメチャンネルの順
3. `OnAmbienceTick` で待機更新 → `WantsStart` なら予算確保 → `TryStartAmbience`
4. 予算不足時は **タイマ据え置き**（次ティックで再挑戦）。打ち直ししない
5. `KomayamaGameClock` 一時停止中はティックもチャンネル更新も進めない
6. 倍速中は scaled のため自然に早く回る

### 3.3 予算（既定）

| 項目 | 値 |
| --- | --- |
| 同時実行コスト上限 | **8** |
| 1 ティックの新規開始上限 | 2 |

各チャンネルの `Cost`（既定 1、**0 可**）を消費。終了時に `ReleaseCost`。常設の軽い演出（胞子雲・熱嚢草）は Cost 0。

**注意**: Cost を常時確保するチャンネルが増えると、上限不足で雲・間欠泉などが永遠に開始できない。常設は 0、単発は 1 を基本とする。

## 4. シーン構成

```text
World/WorldLayers/Layer_Effects
  KomayamaMapAmbienceController
  KomayamaCloudShadowAmbience
  KomayamaSporeCloudAmbience
  KomayamaSwampBubbleAmbience
  KomayamaHeatSacGrassAmbience
  KomayamaGeyserAmbience
  KomayamaDesertDustAmbience
  KomayamaOceanWindAmbience
  KomayamaWestCoastWaveAmbience
  KomayamaFloatBobAmbience
  KomayamaFoxAmbienceAnimChannel
  CloudShadow          … 雲のベース見た目（Scale / Color）。オーサリング用に海の外へ置いてよい
  SporeCloud01〜05     … 胞子雲（位置・Scale・ベース α はシーンで調整）
  GeyserBurst          … 間欠泉（沼付近。噴出中のみ表示）
  DesertDustBand01〜02 … 砂漠砂嵐帯（南端寄り。駆動はチャンネル）
  OceanWindStreak      … 海上風筋（発生は Sea Region_X-1_Y2〜Y6。Scale/α はシーン）
  WestCoastWave        … 西海岸白波（初期位置・Scaleはシーン。毎回そこから開始）
  AmbienceRuntime      … 予備（現状未使用可）

World/WorldLayers/Layer_Continent/…/沼
  Amb_swamp_bubble ×4 … 気泡（位置・最大 Scale はシーン。駆動は Layer_Effects のチャンネル）
  Amb_heat_sac_grass ×4 … 熱嚢草（位置・ベース Scale はシーン。駆動は同上）

World/WorldLayers/Layer_Continent/浮島
  FloatRock_01…        … 旧 OJ浮小岩。同幅・等速上下
  FloatIsle_01…        … 旧 OJ小島。同幅・終端スロー上下
```

- 雲のオーサリング位置は実行時スポーン位置に使わない（カメラ左外へ付け直す）
- 胞子雲のホーム位置は各オブジェクトのワールド座標を採用
- Amb_* は大陸レイヤに置き WASD 追従。チャンネル本体は `Layer_Effects` に置き参照登録
- 間欠泉は環境エフェクトレイヤ固定配置（沼付近）
- 砂漠砂嵐は南端寄りの固定コリドーを左→右（乱数なし）
- 浮小岩／小島は大陸側オブジェクトを `KomayamaFloatBobAmbience` が参照駆動

## 5. 実装済みチャンネル

### 5.1 雲影 — `KomayamaCloudShadowAmbience`（地図）

| 項目 | 仕様 |
| --- | --- |
| 方針 | 時々 **1 枚**だけ流す（同時最大 1） |
| ベース | `CloudShadow` の **Scale・Color（α）を維持** |
| 出現時 Scale | ベース Scale × 倍率 **1.0〜1.8**（ランダム） |
| スプライト | `Assets/Sprites/map_effect/cloud_shadow/` 01〜04・Single / Full Rect からランダム |
| 出現 | カメラ左外。Y はカメラ上下内でランダム（スプライトが収まる範囲） |
| 移動 | 右へ等速。速度ランダム（Inspector `speedMin`〜`speedMax`） |
| 終了 | 完全に右外で非表示にし、ベース Scale / Color に戻す |
| 再出現 | **60 ＋ Random(0〜180) 秒**（ゲーム時間）の後に次を待機 |
| 予算 | Cost 1。流している間だけ消費 |

素材ノートの「α 0.20〜0.35」「待機 6〜20 秒」は**採用しない**（半透明素材のため Color α はベース維持。待機は上記）。

### 5.2 胞子雲 — `KomayamaSporeCloudAmbience`（地図・常設）

| 項目 | 仕様 |
| --- | --- |
| 方針 | **常設・複数**。`SporeCloud01`〜`05` を配列で駆動 |
| 周期 | 個体ごと独立。**8〜14 秒**。開始位相もずらす |
| アルファ | 各個体の **ベース α × 比率**（既定 **0.5〜1.2**）で往復。薄い個体は薄い寄り、濃い個体は濃い寄り |
| 座標 | 各ホームから、画面幅の **1〜3%** だけ周期内で滑らかに移動（急がない） |
| スプライト | シーン上の各 Renderer に割り当てたまま（実行時差し替えなし） |
| 予算 | **Cost 0**（常設・軽いため予算を占有しない） |

素材ノートの「絶対 α 0.15〜0.45」は、ベース α 比率方式に置き換え済み。

### 5.3 狐うたたね — `KomayamaFoxAmbienceAnimChannel`（アニメ）

| 項目 | 仕様 |
| --- | --- |
| 待機 | 無操作 **12 ＋ Random(0〜8) 秒**（unscaled。計測は狐側 `IdleSecondsUnscaled`） |
| 開始 | 予算空き時に `doze_enter` を要求（優先度上限 2） |
| 狐側 | 追従・起床（`NotifyUserActivity`）・クリップ再生は `KCMouseFoxFollower` のまま |
| スキップ | 予算不足時はタイマ据え置き（条件を満たし続ける限り再挑戦） |

### 5.4 沼気泡 — `KomayamaSwampBubbleAmbience`（地図）

| 項目 | 仕様 |
| --- | --- |
| 対象 | `Amb_swamp_bubble` ×4（`Layer_Continent` 配下。参照はチャンネル側） |
| ループ | **待ち 5〜10s（非表示）→ 成長 4〜12s → 一瞬で消える → 同じ待ち**。待ち／成長秒は**起動時に個体ごと固定**（毎ループ再抽選しない） |
| Scale | **0.1 → シーン上の Scale（最大）** |
| α | **0 → 個体ごと 0.3〜0.4**（最大膨らみ時） |
| 起動 | **2 体は成長途中から／残りは待ちから** |
| 予算 | 成長中だけ Cost 1／体。待ちは 0。ティック経由で開始 |
| 負荷 | 成長中だけ軽量 Update。待ちはコスト 0 |

### 5.5 熱嚢草 — `KomayamaHeatSacGrassAmbience`（地図・常設）

| 項目 | 仕様 |
| --- | --- |
| 対象 | `Amb_heat_sac_grass` ×4 |
| 動き | **A＋弱い C**（等方呼吸 ＋ X/Y 逆相のわずかな歪み） |
| 周期 | 個体ごと独立。**静止 40〜80 秒 → 鳴動 2〜6 回 → 静止**。鳴動 1 回＝正弦 1 周期（周期長 2.5〜4.5 秒） |
| 振幅 | 呼吸 ±4%、歪み ±1.75%（Inspector 調整可） |
| 開始 | `Start` で即開始。起動時は静止の途中から（同時鳴動を避ける） |
| 予算 | **Cost 0**（常設・軽いため予算を占有しない） |

### 5.6 間欠泉 — `KomayamaGeyserAmbience`（地図）

| 項目 | 仕様 |
| --- | --- |
| 配置 | `Layer_Effects/GeyserBurst`（沼付近。Sorting `WorldEffect`）。大陸 `Amb_*` ではない |

### 5.7 砂漠砂嵐 — `KomayamaDesertDustAmbience`（地図・常設）

| 項目 | 仕様 |
| --- | --- |
| 配置 | `Layer_Effects/DesertDustBand01`〜`02`。砂漠**中央〜南端寄り**。「これ以上いけない」感用。**Y・Scale は各 Band のシーン値**（実行時に上書きしない） |

| 横断時間 | 穏やか **8 秒**／急 **6 秒**（Inspector 調整可） |

| α | オーサリング α × 比率。穏やか **0.35**／急 **0.7** |

| 1 周期 | パターン **A→B→C→A…**（時間固定・乱数なし） |

| パターン | 穏やか | 急 |
| --- | --- | --- |
| A | 30 秒 | 12 秒 |
| B | 45 秒 | 18 秒 |
| C | 20 秒 | 10 秒 |

| 予算 | **Cost 0**（常設） |

## 8. パフォーマンス（軽量化・保留）

> **トリガー**：ユーザーが「重い」「もっさり」「FPS が落ちる」などと言ったら、この節を見返してから実装するか判断する。  
> **現状判定（2026-09-26）**：対象数が少なく、ホットパスに GC／Find もほぼ無い。**今すぐ必須の軽量化はない。** 本当に重いときはスクリプトより半透明スプライトの overdraw／ドローコールを疑う。

### 8.1 保留案（見た目を変えにくい順）

| 優先 | 対象 | 内容 | 期待効果 |
| --- | --- | --- | --- |
| 1 | `KomayamaFloatBobAmbience` | 小島の上下端停止中は `position` 書き込みをスキップ（値が変わらないフレーム） | 島側の停止時間ぶん CPU 減 |
| 2 | `KomayamaHeatSacGrassAmbience` 等 | Idle／待ちは毎フレーム `Update` せず、`nextWakeTime` または 5 秒ティックへ寄せる | Update オーバーヘッド減 |
| 3 | 胞子・砂帯・風・波など | `SpriteRenderer.color` は変化が閾値未満なら触らない／サイクル開始時に範囲キャッシュ | 微減 |
| 4 | 気泡・砂・雲など | `SetActive` 代わりに Renderer `enabled` のみ切る（要見た目確認） | 活性化コスト減（個数少なら低優先） |
| 5 | 全チャンネル | `Update` をコントローラ1本に集約 | 設計変更大・今の規模ではコスパ悪い |
| 6 | Bob／胞子など | 画面外はティック停止（地図が常時全体表示なら不要） | スクロール運用時のみ有効 |

### 8.2 フレームレート上限（関連）

| 項目 | 状態 |
| --- | --- |
| 目標感 | **無制限 / 60 / 30** を切替可能（既定 **60**） |
| 実装 | `GameFrameRate` ＋ `SoundSettingsManager.GetFrameRateMode` / `SetFrameRateMode`。`playerData.json` の `frameRateMode`（`unlimited`/`60`/`30`）。起動時に適用 |
| UI | 一般タブ `FrameRateRow`（TMP Dropdown：FPS無制限／60FPS／30FPS）。`TitleConfigPanelController` |
| 適用内容 | `QualitySettings.vSyncCount = 0` のうえ `Application.targetFrameRate`（-1 / 60 / 30） |
