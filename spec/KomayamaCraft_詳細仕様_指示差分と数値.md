# KomayamaCraft 詳細仕様（指示差分と数値）

## 0. 文書の位置づけ

- 大本の要件定義は `spec/KomayamaCraft_ゲーム基本仕様.md` のままとする。本書はそれを書き換えない。
- 本書は、基本仕様のあとで指示された差分と、基本仕様に書いていなかった数値の正本とする。
- 個別に既にある詳細はそちらを優先する。
  - Tier 4：`spec/KomayamaCraft_Tier4詳細.md`
  - 素材・設備ライン：`spec/要素設計書/KomayamaCraft_非食材サプライチェーン.md`
  - 保存契約：`spec/データ基盤_保存データ契約.md`
  - 永続ID：`spec/データ基盤_永続ID規約.md`
  - Unityレイヤー：`spec/Unity_初期プロジェクト設定.md`
- 値の書き方
  - **確定**：口頭または文書で明示された値。
  - **現行値**：シーンまたはデータの Inspector に入っている値。確定と違う場合は現行値を優先して実装を読む。

単位のない長さはワールド単位。時間は秒。

## 1. 基本仕様との差分

基本仕様の方針は維持する。次だけが、後続指示で解釈または運用を変えた点である。

| 項目 | 基本仕様 | 後続指示での確定 |
| --- | --- | --- |
| 手持ちの品種 | 手持ちへ入れる、とだけ書く。品種制限は書いていない | 異なるアイテムを同時に持てる。上限は合計個数 |
| 手持ちの見せ方 | 書いていない | マウスカーソルの**右横**にアイコンを並べる。テキストだけにしない |
| 手持ち上限 | 書いていない。M2タスクは1品種・仮上限 | アップグレード完了時 **100**。いまのテスト上限は **10** |
| 採集の再生待ち | どのTierでも待ち時間なし | 同じ。素材の刈り取り待ちは **0** |
| 自動採集 | Ghostの仕事。発生点は自動では産出しない | 同じ。発生点そのものの自動産出は作らない |
| 通貨 | 採用しない | 同じ。契約などの報酬も物品だけ。M8案の通貨は採用しない |
| ドロップ位置 | 産出点から論理上のドロップ中心へ向かい、放物線で着地。押しのけあり | 着地位置は発生点中心からの円環。初回半径の円が一杯なら半径を **1.1アイテム分** 広げる。放物線は着地までの演出 |
| ドロップが詰まったとき | 押しのけを定義。消滅は書いていない | 許可範囲と円環を使い切ったときだけ産出失敗し、その1個は出ない |
| ドロップ禁止 | `NoDropPaint` セル **0.5**。建設判定と共有しない | 同じ。建設不可塗りは別Tilemap |
| ドロップ禁止の内側 | 書いていない | 禁止塗りでなくても、発生点の**実際の絵の内側**には落とさない。枠の余白には落としてよい |
| マイルストーン | 初期案では M6=T2〜3、M7=1周、M8=周辺（通貨含む） | 実装順は M6=Tier2、M7=Tier3、M8=Tier4短いライン、M9=通し品質。周辺は後工程 |
| Tier 4 | 今後の詳細設計 | 生素材1・設備1・最終部品1。詳細は `KomayamaCraft_Tier4詳細.md` |
| ワールド広さ | 見下ろし固定フィールド、16:9 | 不時着船を中心に、ズーム1倍で横 **10** 画面・縦 **6** 画面を大陸として確保 |

基本仕様 §16 のセーブ、タイトル、危険領域、クリア後復帰は、後続指示を基本仕様へ既に書いた内容である。本書では数値だけ補う。

## 2. 手持ちとカーソル表示

### 2.1 容量

| 項目 | 値 | 区分 |
| --- | --- | --- |
| テスト中の手持ち上限 | 10個 | 確定 |
| アップグレード等をすべて終えた上限 | 100個 | 確定 |
| 上限の意味 | 種類を問わない合計個数 | 確定 |
| 同じ種類だけの制限 | しない | 確定 |

満杯（現行は10個）のときは拾えない。既存の手持ちは消さない。理由は「手持ちが満杯です」。

設定場所は `KCConfigValues / アイテム設定`。

- `HandCapacity`：いまの上限。現行値 10
- `HandCapacityMax`：最終上限。現行値 100

### 2.2 並びと折り返し

- 表示は同じアイテムでまとめる。
- まとめ順は、最初に拾った種類が先。あとから同じ種類を拾ったら、先に出ている塊へ寄せる。
- 例：鉄 → 実 → 鉄 と拾うと、カーソル右は **鉄鉄実**。
- 個数 `n/n` はカーソル右横の固定位置。手持ちが空なら非表示。アイテムを拾ってもこの位置は動かさない。
- アイテムは `n/n` の**1段下**から右へ並べ、**10個**で改行する。
- 同じ段で **5個** 並べたあと、次のアイテムまでの隙間を **0.2アイテム分** 余分に空ける。
- 右クリックで地面へ置くとき、表示上いちばん左（最初の塊）の1個を置く。
- 設備へ投入するときは、その設備が受け取れる種類を手持ちから探す。表示先頭だけに限定しない。

### 2.3 カーソル上の大きさ

- アイコンは地面のドロップ品より小さくする。確定。
- 表示は `World / Layer_Mouse`。`WorldLayers` より前、`Layer_System` より後ろ。
- マウスを動かしたら、拾った一覧もカーソル右横へ追従する。
- 大きさはドロップ見た目サイズ × `CursorIconScale`。現行値 **0.45**。
- 個数は子オブジェクト `HandCount` に `現在/上限` を出す。空のときは出さない。
- カーソル上のアイコンは当たり判定を持たない。
- HUD左下の手持ち文は種類ごとの個数と `合計/上限` を出す。例：`手持ち: 鉄鱗×2 熱嚢草の嚢×1 (3/10)`。

## 3. 地面ドロップ

### 3.1 共通サイズ（全ドロップ品で同じ）

設定場所は `KCConfigValues / アイテム設定`。

| 項目 | 現行値 | 意味 |
| --- | --- | --- |
| 見た目サイズ | 幅 1 × 高さ 1 | 絵を差し替えても、この枠に縦横比を保って収める |
| 取得判定半径 | 0.5 | 左クリックで拾える円。見た目・押しのけとは別 |
| 押しのけ半径 | 0.4 | ドロップ同士が重ならないように離す円 |
| 採集ドロップ円半径 | 2 | 発生点中心から時計回りに置く固定円。半径は増やさない |

採集ドロップ円半径 **2** は後続指示で決めた。見た目 1×1・取得 0.5・押しのけ 0.4 は現行 Inspector。円の拡大（1.1アイテム分）は廃止。

### 3.2 散らばり方

1. 発生点の中心を原点にする。
2. 円の半径は採集ドロップ円半径（現行 2）。半径は増やさない。
3. その円上を、12時方向から時計回りに置く。
4. 次の角度は等間隔にしない。1枠分の角度を基準に、**0.25倍〜2.0倍**の乱数で進める。最大で約1個分飛ばしてよい。
5. 候補が禁止塗り、DropArea外なら、時計回りに少しずらす。発生点の絵の内側は自動では禁止しない（禁止は塗りで指定する）。
6. 円上の許可点が見つかったら、新しい1個をその点に**固定**してねじ込む。既存ドロップだけが接触の連鎖で動く。左右入れ替え禁止はしない。
7. 押しのけ先が禁止塗り・DropArea外なら、その移動は途中の許可位置までに止める（硬い壁）。
8. 円上に置ける点が見つからなければその1個は出さない。メッセージは「置ける場所がないため、素材が消滅しました」。

手置き（右クリック）も同じ押しのけ。カーソルの指定位置に新しい1個を固定してねじ込む。指定位置が禁止塗りまたは DropArea 外なら失敗する（近くへ逃がさない）。重なっている既存ドロップは近いほど大きく、接触が遠いほど少しだけ動く。セーブ復元は保存座標へ押しのけなしで戻す。

地面の計算上の上限は FieldDropArea の「地面の最大個数」（現行 **800**、500未満にはしない）。隙間がある限り最低500個は置ける。セーブ復元はこの上限を使わない。本当に壁と禁止塗りで隙間が尽きたとき、または上限に達したときだけその1個は出ない。

### 3.3 演出と実装上限

| 項目 | 現行値 |
| --- | --- |
| 飛び出し時間 | 0.4秒。発生点から着地まで見た目が移動する。山なりは使わない |
| 押しのけ移動時間 | 0.45秒。EaseInOutBackで行き過ぎて戻る（ぷよっとした緩急）。距離が長いほど少し長くなる |
| 押しのけ | 指定位置へ固定ねじ込み。空間ハッシュ＋接触連鎖。減衰 0.55、最大ホップ 12、落ち着き反復 3 |
| 地面の最大個数 | 800（最低500） |
| 押しのけ中の回収 | できない（基本仕様どおり） |
| 同一円上のずらし回数上限 | 64 |
| 禁止塗りの判定 | その座標の塗りセルだけ。押しのけ半径や発生点コライダーでは自動禁止しない |

### 3.4 ドロップできる範囲

- フィールドにあらかじめ `FieldDropArea` を置く。この外には散らばらないし、手でも置けない。
- 現行の判定箱：サイズ **192 × 64.8**、オフセット **(-7.5, 3.2)**。大陸予約と同じ。
- ドロップ禁止は `World / DropRestrictionGrid / NoDropPaint`。`WorldLayers` の下には置かない。
- `NoDropPaint` のセルは **0.5 × 0.5**。Scene View は半透明。プレイ中はデバッグ表示がオンのときだけ同じ表示。
- 建設不可塗りは別。ドロップ禁止と共有しない。

### 5.2 レイヤー

描画は次の4段。親は `World / WorldLayers`。

| 子 | Sorting Layer |
| --- | --- |
| 海 | `WorldSea` |
| 大陸 | `WorldContinent` |
| オブジェクト | `WorldObject` |
| エフェクト | `WorldEffect` |

`WorldLayers` の上（`World` 直下の兄妹）に、次を置く。

| オブジェクト | Sorting / Canvas | 役割 |
| --- | --- | --- |

ドロップや禁止塗りのデバッグ表示など、エフェクトより前・マウスより後ろに出すものは `WorldOverlay`。

## 6. フィールドオブジェクトの見た目

- 根の Scale は 1 のままにする。大きさは表示枠で決める。
- 子 `見た目` が `SpriteRenderer` を持つ。絵は枠へ contain（縦横比維持、はみ出しなし）。
- 当たり判定は枠に合わせる。ドロップ禁止判定に使う「絵の内側」は、枠ではなく実際に描いているスプライト範囲。
- 鉄鱗獣・熱嚢草の枠は配置時に **5 × 5** とした。製品値としての固定ではなく、いまの配置値。

## 8. 進行・セーブ・案内

基本仕様 §16 の補数。

| 項目 | 値 |
| --- | --- |
| オートセーブ間隔 | 120秒（約2分） |
| 終了時セーブ | する |
| 手動セーブ | F5 |
| 読込 | F9 とタイトル「続きから」 |
| スロット数 | 3 |
| 新規開始 | 空きスロットはそのまま開始。使用中は上書き確認 |
