- 大本の要件定義は `spec/KomayamaCraft_ゲーム基本仕様.md` のままとする。本書はそれを書き換えない。
- 本書は、基本仕様のあとで指示された差分と、基本仕様に書いていなかった数値の正本とする。
- 個別に既にある詳細はそちらを優先する。

## 1. 基本仕様との差分

基本仕様の方針は維持する。次だけが、後続指示で解釈または運用を変えた点である。

| 項目 | 基本仕様 | 後続指示での確定 |
| --- | --- | --- |
| 手持ちの品種 | 手持ちへ入れる、とだけ書く。品種制限は書いていない | 異なるアイテムを同時に持てる。上限は合計個数 |
| 手持ちの見せ方 | 書いていない | マウスカーソルの**右横**にアイコンを並べる。テキストだけにしない |
| 手持ち上限 | 書いていない。M2タスクは1品種・仮上限 | アップグレード完了時 **100**。いまのテスト上限は **50**（現行 Inspector） |
| 採集の再生待ち | どのTierでも待ち時間なし | 同じ。素材の刈り取り待ちは **0** |
| 自動採集 | Ghostの仕事。発生点は自動では産出しない | 同じ。発生点そのものの自動産出は作らない |
| 通貨 | 採用しない | 同じ。契約などの報酬も物品だけ。M8案の通貨は採用しない |
| ドロップ位置 | 産出点から論理上のドロップ中心へ向かい、放物線で着地。押しのけあり | 採集は発生点中心の**固定半径の円上**を時計回り。半径は広げない。手置きはカーソル位置へ固定ねじ込み。押しのけは接触連鎖（コイン机）。着地までの移動は演出 |
| ドロップが詰まったとき | 押しのけを定義。消滅は書いていない | 円上／指定位置が禁止または DropArea 外、地面上限、隙間なしのときその1個は出ない |
| ドロップ禁止 | `NoDropPaint` セル **0.5**。建設判定と共有しない | 同じ。建設不可塗りは別Tilemap。禁止塗りと DropArea 端は押しのけの**硬い壁** |
| 発生点の内側 | 書いていない | 発生点の絵の内側は**自動では禁止しない**。禁止は `NoDropPaint` で指定する |
| 初期フィールドの設備 | 書いていない | 生産・精製施設はシーンにあらかじめ置かない。建設メニューから置く。クリック／ドロップ範囲を建設不可にする方針（実装は後続） |
| マイルストーン | 初期案では M6=T2〜3、M7=1周、M8=周辺（通貨含む） | 実装順は M6=Tier2、M7=Tier3、M8=Tier4短いライン、M9=通し品質。周辺は後工程 |
| Tier 4 | 今後の詳細設計 | 生素材1・設備1・最終部品1。詳細は `KomayamaCraft_Tier4詳細.md` |
| ワールド広さ | 見下ろし固定フィールド、16:9 | 不時着船を中心に、ズーム1倍で横 **6** 画面・縦 **8** 画面を大陸として確保 |

基本仕様 §16 のセーブ、タイトル、危険領域、クリア後復帰は、後続指示を基本仕様へ既に書いた内容である。本書では数値だけ補う。

## 2. 手持ちとカーソル表示

### 2.1 容量

| 項目 | 値 | 区分 |
| --- | --- | --- |
| テスト中の手持ち上限 | 50個 | 現行値（確定の最終上限は100） |
| アップグレード等をすべて終えた上限 | 100個 | 確定 |
| 上限の意味 | 種類を問わない合計個数 | 確定 |
| 同じ種類だけの制限 | しない | 確定 |

満杯のときは拾えない。既存の手持ちは消さない。理由は「手持ちが満杯です」。

設定場所は `KCConfigValues / アイテム設定`。

- `HandCapacity`：いまの上限。現行値 **50**
- `HandCapacityMax`：最終上限。現行値 **100**

### 2.2 並びと折り返し

- 表示は同じアイテムでまとめる。
- まとめ順は、最初に拾った種類が先。あとから同じ種類を拾ったら、先に出ている塊へ寄せる。
- 例：鉄 → 実 → 鉄 と拾うと、カーソル右は **鉄鉄実**。
- 個数 `n/n` はカーソル右横の固定位置。手持ちが空なら非表示。アイテムを拾ってもこの位置は動かさない。
- アイテムは `n/n` の**1段下**から右へ並べ、**10個**で改行する。
- 同じ段で **5個** 並べたあと、次のアイテムまでの隙間を **0.2アイテム分** 余分に空ける。
- 右クリックで地面へ置くとき、表示上いちばん左（最初の塊）の1個を置く。
- 設備へ投入するときは、その設備が受け取れる種類を手持ちから探す。表示先頭だけに限定しない。

### 2.3 カーソル上の大きさ

- アイコンは地面のドロップ品より小さくする。確定。
- 表示は `World / Layer_Mouse`。`WorldLayers` より前、`Layer_System` より後ろ。
- マウスを動かしたら、拾った一覧もカーソル右横へ追従する。
- 大きさはドロップ見た目サイズ × `CursorIconScale`。現行値 **0.45**。
- 個数は子オブジェクト `HandCount` に `現在/上限` を出す。空のときは出さない。
- カーソル上のアイコンは当たり判定を持たない。
- HUD左下の手持ち文は種類ごとの個数と `合計/上限` を出す。例：`手持ち: 鉄鱗×2 熱嚢草の嚢×1 (3/50)`。

## 3. 地面ドロップ

### 3.1 共通サイズ（全ドロップ品で同じ）

設定場所は `KCConfigValues / アイテム設定`。

| 項目 | 現行値 | 意味 |
| --- | --- | --- |
| 見た目サイズ | 幅 0.4 × 高さ 0.4 | 絵を差し替えても、この枠に縦横比を保って収める |
| 取得判定半径 | 0.12 | 左クリックで拾える円。見た目・押しのけとは別 |
| 押しのけ半径 | 0.14 | ドロップ同士が重ならないように離す円 |
| 採集ドロップ円半径 | 1.5 | 発生点中心から時計回りに置く固定円。半径は増やさない |

採集ドロップ円半径の拡大（1.1アイテム分）は廃止。見た目・取得・押しのけ・円半径は現行 Inspector。

**絵の差し替え**

- 地面ドロップとカーソル手持ちの絵は、ドロップ prefab ではなく各 `ItemDefinition` の **Icon**。
- 実行時にドロップ見た目へ Icon を載せ、大きさは上記「見た目サイズ」で揃える。
- 現行例：鉄鱗＝`Assets/Sprites/item/drop_鉄鱗.png`、熱嚢草の嚢＝`Assets/Sprites/item/drop_熱嚢.png`。鉄鱗板は仮アイコン（`tile_cog`）。

### 3.2 ドロップ操作（右クリック）

設定場所は同じ `アイテム設定` の「ドロップ操作」。

| 項目 | 現行値 | 意味 |
| --- | --- | --- |
| 長押し判定までの時間 | 0.38 | 右クリックを押してから連続ドロップが始まるまでの秒 |
| 連続ドロップ間隔 | 0.05 | 長押し判定後、1個ずつ置く間隔。0なら毎フレーム1個 |
| 最大アイテム数 | 1000 | 地面に同時に置ける上限。500未満にはしない |

デバッグの「長押しで超速連打」は**左クリックの採集／拾いだけ**に効く。右クリックのドロップ速度には効かない。

### 3.3 散らばり方と押しのけ

手置きと採集ドロップは**同じ押しのけ**を使う。違うのはねじ込む座標だけ。

**採集**

1. 発生点の中心を原点にする。
2. 円の半径は採集ドロップ円半径。半径は増やさない。
3. その円上を、12時方向から時計回りに置く。
4. 次の角度は等間隔にしない。1枠分の角度を基準に、**0.25倍〜2.0倍**の乱数で進める。
5. 候補が禁止塗り、DropArea外なら、時計回りに少しずらす（最大64回）。発生点の絵の内側は自動では禁止しない。
6. 円上の許可点が見つかったら、新しい1個をその点に**固定**してねじ込む。
7. 円上に置ける点が見つからなければその1個は出さない。メッセージは「置ける場所がないため、素材が消滅しました」。

**手置き（右クリック）**

- カーソル下の当たりを `OverlapPointAll` で見て、次の順で処理する（後ろが重なっていても先の対象を選ぶ）。
  1. 納入ゴミ箱（`KomayamaDepositBin`）
  2. 加工設備（`KomayamaProcessingFacility`）
  3. 保管（`KomayamaStorageFacility`）
  4. 地面ドロップ（DropArea 内）
- 地面へ置くとき、カーソルの指定位置に新しい1個を固定してねじ込む。
- 指定位置が禁止塗りまたは DropArea 外なら失敗する（近くへ逃がさない）。

**押しのけ（コイン机）**

- 新しい1個は動かさない。既存だけが動く。
- 重なっている隣から接触を連鎖させる。近いほど大きく、遠いほど少し（減衰つき）。
- 左右入れ替え禁止はしない。
- 禁止塗りと DropArea 端は硬い壁。押しのけ先が壁なら途中の許可位置までに止める。
- 実装は空間ハッシュ＋接触連鎖。落ち着き反復で近傍の残り重なりを隙間へ落とす。
- セーブ復元は保存座標へ押しのけなし・演出なしで戻す。地面上限は使わない。

地面に同時に置ける計算上の上限は「最大アイテム数」（現行 **1000**）。隙間がある限り最低500個は置ける想定。上限到達、または壁と禁止塗りで隙間が尽きたときだけその1個は出ない。

### 3.4 演出と実装上限

| 項目 | 現行値 |
| --- | --- |
| 飛び出し時間 | 0.4秒。発生点／カーソルから着地まで見た目が移動する。山なりは使わない |
| 押しのけ移動時間 | 0.45秒。EaseInOutBackで行き過ぎて戻る。距離が長いほど少し長くなる |
| 押しのけ | 固定ねじ込み。空間ハッシュ＋接触連鎖。減衰 0.55、最大ホップ 12、落ち着き反復 3（FieldDropArea） |
| 最大アイテム数 | 1000（最低500）。アイテム設定のドロップ操作 |
| 押しのけ中の回収 | できない（基本仕様どおり） |
| 同一円上のずらし回数上限 | 64 |
| 禁止塗りの判定 | その座標の塗りセルだけ。押しのけ半径や発生点コライダーでは自動禁止しない |

### 3.5 ドロップできる範囲

- フィールドにあらかじめ `FieldDropArea` を置く。この外には散らばらないし、手でも置けない。
- 現行の判定箱：サイズ **115.2 × 86.4**、オフセット **(-7.5, 3.2)**。大陸予約と同じ。
- ドロップ禁止は `World / DropRestrictionGrid / NoDropPaint`。`WorldLayers` の下には置かない。
- `NoDropPaint` のセルは **0.5 × 0.5**。Scene View は半透明。プレイ中はデバッグ表示がオンのときだけ同じ表示。
- 建設不可塗りは別。ドロップ禁止と共有しない。

## 6. フィールドオブジェクトの見た目

- 根の Scale は 1 のままにする。大きさは表示枠で決める。
- 子 `見た目` が `SpriteRenderer` を持つ。絵は枠へ contain（縦横比維持、はみ出しなし）。
- 当たり判定は枠に合わせる（`KCSpriteFrame` が親のコライダーを枠へ同期）。
- 鉄鱗獣・熱嚢草の枠は現行 **2 × 2**。製品値としての固定ではなく、いまの配置値。
- 発生点の絵の内側はドロップ自動禁止にしない。禁止は `NoDropPaint` で塗る。

| 検証用保管 | 検証用原料 2 | — | — | — | 20 |

### 7.1 納入ゴミ箱

加工施設とは別オブジェクト。右クリックで手持ちの先頭1個を納入し、そのアイテムは消える（保管しない）。

| 項目 | 内容 |
| --- | --- |
| 配置 | `World / WorldLayers / Layer_Objects` 直下。Layer は `NativeLife`（資源発生点と同じ） |
| 構造 | 根 + 子 `見た目`（`SpriteRenderer` + `KCSpriteFrame`）。根に `BoxCollider2D` と `KomayamaDepositBin` |
| 反応範囲 | 見た目枠の広さ＝コライダー。枠を変えれば右クリック反応範囲も変わる |
| 長押し | 右クリック連続ドロップと同じ間隔（アイテム設定）で連続納入できる |
| 優先 | 右クリック時、加工・保管・地面より先。地面アイテムや上限で置けない場合でもゴミ箱へ入る |
| 初期例 | シーンの `納入ゴミ箱`（仮見た目 `trash_close`） |

### 7.2 カーソル追従狐（`FoxCursorFollower`）

`World / Layer_Mouse / FoxCursorFollower`（`KCMouseFoxFollower`）。Sorting は `WorldMouse`。手持ちアイコンとは別オブジェクト。マウスの**左側少し離れた位置**を追い、揺れアニメを再生する。

#### 7.2.1 表示モード

表示モードは次の3つ。初期はマウス追従。

| モード | 挙動 |
| --- | --- |
| マウス追従 | カーソル位置＋オフセットを目標に追従する。WASD／マップドラッグでカメラが動いても、常にマウス相対 |
| 画面配置 | **ディスプレイ（画面）に対して定位置**。カメラが動いても狐の画面上の位置は変わらない。ワールド座標に置かない |
| OFF | 表示しない。入力・アニメ評価もしない |

**モード切替**

- 当面は **Inspector のみ**。
- 将来はスキル解放後に UI から変えられる。UI・解放条件の詳細は後続指示。

**画面配置モードの操作**

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | 狐を掴んで画面上の位置を変える |
| マウスオーバー＋ホイール | 大きさを変える。下限・上限は Inspector（本書に数値は書かない） |

採集・ドロップなど他の左クリック操作と重なったときは **狐を優先**する（ドラッグ開始・ホイールを狐が取る）。

マウス追従時のオフセット・追従速さ・基準の見た目サイズは **Inspector で調整できる**。

| 項目 | 現行値 | 意味 |
| --- | --- | --- |
| `cursorOffset` | (-1.1, -1.1) | マウス追従時のカーソルからのオフセット。左へ離すなら X を負に |
| `followSpeed` | 12 | SmoothDamp の追従速さ |
| `displayHeight` | 2.4 | 基準の見た目高さ。幅は縦横比を保つ |

各アニメのコマ表示秒は画像ごとに設定する（現行 `secondsPerFrame`）。Frames の枚数に配列を揃える。足りない分は末尾の値、空なら 0.1 秒。下限 0.02 秒。

#### 7.2.2 セーブ

次をセーブ／ロードする。

- 表示モード（マウス追従／画面配置／OFF）
- 画面配置モードの位置
- 画面配置モードの大きさ

#### 7.2.3 アニメーション定義

各アニメは次を持つ。

| 項目 | 内容 |
| --- | --- |
| 優先度 | 1〜5（下表） |
| 素材 | `Assets/Sprites/chara/` 配下の画像／スプライトシート |
| コマ列 | スプライト配列。各コマの表示秒は画像ごとに設定可（`secondsPerFrame`） |
| 再生方向 | **片道が既定**。末尾の次は**先頭へ戻る**（往復しない）。往復（ping-pong）は定義で ON にしたときだけ。現行クリップはすべて OFF |
| 再生種別 | **ループ** または **回数指定** |
| 発火条件 | 下表のクリップ定義どおり |
| 終了条件 | 優先度5・4は**必須**。ループは終了条件を満たすか上書きまで続く |
| 次アニメ | 回数指定が規定回数を終えたあとへ移る先。空／無効なら優先度1（`base`）へ |

**再生種別**

- **ループ**：コマを 0→末尾→0… と繰り返す。終了条件を満たすか、より高い／同位後勝ちのアニメに上書きされるまで続く。
- **回数指定**：指定回数だけ再生（1サイクル＝コマを先頭から末尾まで1周）したら終了し、**次アニメ**へ移る。次が空／無効なら優先度1。

#### 7.2.4 優先度

| 優先度 | 名称 | 意味 | 終了条件 |
| --- | --- | --- | --- |
| 5 | システム | チュートリアル等、イベント発火。必ず終了条件がある | 必須 |
| 4 | アクション | クリック等、ユーザ操作発火。必ず終了条件がある | 必須 |
| 3 | 状況演出 | WASD／画面移動時のぶらぶら等。無くてもゲーム体験に致命傷はない | 定義による |
| 2 | 待機系 | 無操作のうたたねなど | 定義による |
| 1 | デフォルト | 他条件を満たさないときの常時再生 | なし（常時候補） |

- 優先度1のアニメは **必ずちょうど1個**。実装時にシステム側で保証する。

#### 7.2.5 クリップ一覧（現行）

素材ルートは `Assets/Sprites/chara/`。コンポーネントは `KCMouseFoxFollower`。

| ID | 優先度 | 素材 | 種別 | 発火 | 終了／遷移 |
| --- | --- | --- | --- | --- | --- |
| `base` | 1 | `base.png` | ループ（既定ポーズ） | 他に該当がないとき常時 | なし（常時候補） |
| `doze_enter` | 2 | `fox_doze_enter_spritesheet_4x1.png` | 回数 **1** | 左右クリック・画面移動・マウス移動・キー操作がいずれも無い状態が、**一定時間＋ランダム一定時間**経過したとき | 1回再生後 → `doze_loop` |
| `doze_loop` | 2 | `fox_doze_loop_spritesheet_5x1.png` | ループ | `doze_enter` からの次アニメとして再生 | **何か操作**したら停止（再評価。通常は `base`） |
| `dangle` | 3 | `fox_dangle_spritesheet_5x1.png` | ループ | WASD／マップドラッグ等で**画面（カメラ）移動を開始**したとき | **画面移動を止めた**とき |
| `pickplace` | 4 | `fox_idle_pickplace_spritesheet_4x2.png` | ループ | **右クリック長押しでドロップ中**（手持ちがあり右ボタン押下中） | 右クリックを離した／手持ちが空になったとき |
| `gather_sword` | 4 | `fox_invisible_sword_spritesheet_4x2.png` | 短押し／長押しで異なる（下節） | 有効なクリック採集 | 下節 |
| `spin_test` | 5 | `fox_idle_spin_spritesheet_4x2.png` | 回数 **3** | **システムキック**（テスト）。プレイ開始／再開から **6秒後に1回だけ**。本番用キックは後続 | 3回再生で終了（次は空→`base`） |

**うたたねまでの時間（Inspector）**

| 項目 | 意味 |
| --- | --- |
| `dozeIdleBaseSeconds` | 無操作の基本待ち |
| `dozeIdleRandomSeconds` | 基本待ちのあとに足すランダム幅（0〜この値） |

実際の開始は「基本＋0〜ランダム」秒後。製品の固定秒は本書に書かない。

**`gather_sword`（採集）の再生**

| 操作 | 再生 |
| --- | --- |
| 短押し（1回採集して離す） | クリップの `secondsPerFrame`（設定コマ秒）で **1回**再生。離しても最後まで流す |
| 長押し（同一発生点で連続採集に入ったあと） | 採集の長押し間隔（入力の採集間隔。強化で変わり得る）を**コマ数で等分**した秒で、押しているあいだ**ループ**。離したら解除して `base` へ |

長押しモードへの切替は、初回採集のあと「次の連打採集が発火したとき」（＝採集間隔が経過してまだ押しているとき）。

補足:

- `doze_enter` → `doze_loop` は同じ優先度2の連鎖。上位（3〜5）が割り込んだら即中断し、スタック復帰しない。
- `pickplace` と `gather_sword` は同位4。同時条件なら**後勝ち**。
- `spin_test` の6秒キックはテスト専用。本番では別キックに差し替える。
- セーブ版は `KomayamaCraftSaveData` version **4**（狐のモード・画面位置・大きさを含む）。

#### 7.2.6 切替規則（スタックしない）

同時に「再生中」は常に **1本だけ**。

1. **上位が下位を上書き**：下位再生中に上位の発火条件が満たされたら、下位を**即中断**して上位を開始する。
2. **上位は下位で中断しない**：上位再生中に下位の条件を満たしても、上位は続け、下位は開始しない。
3. **スタックしない**：上位が終了しても、中断していた下位を再開しない。終了後はその時点の条件で再評価し、該当する最上位を選ぶ。該当がなければ優先度1（`base`）。
4. **同位は後勝ち**：同じ優先度の別アニメが発火したら、先の再生を中断し、後から発火した方を必ず開始する。
5. **回数指定の完了**：規定回数終了後は次アニメへ移る。次が空／無効なら優先度1。スタック復帰はしない。

#### 7.2.7 実装メモ（参照）

- 画面配置はカメラ追従のワールド子にしない。画面固定（ビューポート座標など）とする。
- OFF 中は表示を消し、ドラッグ・ホイール・アニメ評価を止める。
- システム発火（優先度5）は、他システムから「アニメIDを再生要求」できる入口を持つ。`spin_test` はその入口のテスト利用。
- 採集・カメラ移動・右クリックドロップの通知は `KomayamaCraftInputController` / `KomayamaCraftCameraController` から行う。
