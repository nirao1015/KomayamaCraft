# KomayamaCraft 自動化プレイテスト 詳細仕様

> **状態**：P0（チュートリアル：OP→雨漏り初期納品→**宇宙船修理演出まで再生**→終了アサート）**実装済み・常緑ゲート運用**。MainOnly／All の汎用ランナーは後続。
> **入口**：`KomayamaCraftDebugManager` の「チュートリアル自動プレイ」（本番リリース用 ON では無効）。
> **常緑**：クエスト／会話／フィールド操作を触ったら §11 に従い P0 を 1 回通す。

## 0. 文書の位置づけ

| 項目 | 内容 |
| --- | --- |
| 目的 | 人手プレイなしで、クエスト進行に必要な操作を**疑似入力**で通し、進行・納品・解放が壊れていないかを確認する |
| 非目的 | ユニットテスト、セーブ改ざんによる進行スキップ、施設内部 API を直接叩いて結果だけ作ること |
| 関連 | 施設加工操作・建設・クエストログ・会話オーバーレイ・NPC インタラクト。クエスト台帳はクエスト設計文書が正本 |
| 値の書き方 | **確定**／**提案**／**後続定義** |

## 1. やりたいこと（要約）

開発中に、次のモードで「プレイヤーがやっているのと同じ操作経路」を自動実行できる。

| モード | 内容 | 区分 |
| --- | --- | --- |
| **チュートリアル自動プレイ（P0・実装済み）** | OP → 現状把握（WASD）→ 雨漏り初期納品 → **宇宙船修理演出を再生** → 終了アサート | 確定 |
| **メインのみ（後続）** | メインクエストカテゴリだけを完走 | 確定（未実装） |
| **全部（後続）** | メイン＋サブ等（消化順は §6.2） | 確定（未実装） |

操作は「内部関数で在庫を足す／クエスト完了フラグを立てる」ではなく、

- マウスを対象の上へ重ねた扱い
- 左／右クリックした扱い（メニュー UI 上のレシピ選択含む）
- WASD 長押し相当
- 会話の**テキスト送り**（左クリック相当。スキップボタン相当ではない）

として、**既存の入力・インタラクト経路と同じ口**を通す。

## 2. 原則

### 2.1 疑似入力原則（確定）

| 原則 | 内容 |
| --- | --- |
| 同じ経路 | 採集・拾い・投入・メニュー開閉・レシピ選択・建設・納品は、通常プレイと同じコントローラ／インタラクト処理を通る |
| 疑似ポインタ | 実マウスの代わりに、ワールド座標の**強制ポインタ**を置き、左／右クリック相当を発行する |
| 禁止 | 進行だけを飛ばすデバッグ完了 API、施設の入力直叩き、クエスト完了フラグの直書き（※失敗時の診断用ログは可） |
| 許可する観測 | クエスト進行状態・監視フラグ・手持ち・地面ドロップ・仮組／完成施設など、**ヒエラルキー上の公開情報の読み取り** |
| 許可する補助 | **カメラの対象付近へのスナップ**。ゲーム状態の捏造はしない |
| 時間加速との分離 | ゲーム全体の倍速は DebugManager の**独立機能**（§2.4）。自動化はそれを**変更・操作しない** |

### 2.1.1 スキップ禁止（確定）

オートプレイでは **スキップ系を基本使わない**。本番プレイヤーと同じ経路で最後まで通す。

| 禁止 | 内容 |
| --- | --- |
| 会話スキップボタン | 使わない。**テキスト送り**（左クリック／スペース相当）のみ |
| 演出の ForceSkip／長押しスキップの自動発火 | 宇宙船修理など演出を自動で打ち切らない |
| OP スキップ | 自動プレイ ON のときは「OP演出しない」より**優先して OP を通す**（§2.3） |
| 進行のデバッグ完了 | クエスト完了フラグ直書き・在庫直加算による飛ばし |

許可するのは疑似入力（クリック・WASD・会話送り）とカメラのスナップのみ（§2.1）。

### 2.2 意思決定（確定・P0）

| 項目 | 内容 |
| --- | --- |
| 方式 | **手順再生（固定ステップ列）ではなく、状態観察型** |
| 周期 | 一定間隔でワールド／クエストを読み、次の 1 操作を決める |
| 会話中 | ワールド操作はせず、テキスト送りパルスのみ |
| 停止 | `main_rain_leak` が **Completed** かつ船修理演出が非再生になったら自動停止（§11） |

### 2.3 DebugManager 上の位置（確定）

| 項目 | 内容 |
| --- | --- |
| 起動 | Inspector「チュートリアル自動プレイ」ON → Play 開始時に専用コントローラが開始 |
| 本番 | `本番リリース用` ON のときは起動不可 |
| OP | 自動プレイ ON のときは「OP演出しない」より**優先して OP を通す**（新規セッション時） |
| 実行形態 | `KomayamaCraftAutoPlayController` ＋ `KomayamaCraftAutoPlayInput` |

### 2.4 ゲーム倍速・一時停止（確定）

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 正本 | `KomayamaGameClock` → `Time.timeScale` | 確定 |
| デバッグ倍率 | 0.5 / 1 / 3 / 5 / 10（`DebugCanvas/ButtonSpeed`） | 確定 |
| 自動化テスト | 倍速・一時停止を自動ではいじらない | 確定 |
| WASD 目標 | 現状把握のキー長押し必要秒はクエスト側（現行 **0.8** 秒） | 確定 |

## 3. 全体構成（P0・実装）

```text
[KomayamaCraftDebugManager]
   ├─ ゲーム倍速 …… 自動化からは操作しない
   └─ startTutorialAutoPlay
         └─ [KomayamaCraftAutoPlayController]
               ├─ ThinkLoop …… 状態観察 → 次操作
               ├─ DialogueAdvancePulse …… 左クリック送り相当
               └─ KomayamaCraftAutoPlayInput …… HoldWASD / 強制ポインタ / 送り要求

[KomayamaCraftInputController]
   └─ AutoPlayLeftClickAt / AutoPlayRightClickAt → 既存 HandleLeft / HandleRight
```

後続の汎用構成（MainOnly／All・シナリオ台帳・IAutoPlaytestTarget）は §9。

## 4. 疑似入力（P0・実装）

### 4.1 能力（確定）

| 操作 | 意味 |
| --- | --- |
| 強制ワールドポインタ＋左クリック | 採集・拾い・施設メニュー・NPC 会話 |

疑似クリック前に、対象付近へ `SnapToWorldCenter` してよい。

## 5. P0 で観測してよい状態（確定）

内部値の書き換えは禁止。次の**読み取り**は許可する。

| 観測 | 用途例 |
| --- | --- |
| クエスト Status／目標完了／カウンタ | 次フェーズ判定 |
| `IsAwaiting*` 監視フラグ（配置・建設投入・レシピ・生産・納品・採集） | 会話待ち中に早置きしない |
| 手持ちアイテム定義 ID・個数 | 投入／納品の可否 |
| 地面ドロップ（定義 ID・位置） | 拾い対象 |
| 仮組／完成の基礎加工台 | 配置・投入・レシピ・生産 |
| 会話／OP アクティブ | 送り専用モード |

## 6. P0 到達範囲（確定）

| 区間 | 内容 |
| --- | --- |
| 開始 | OP（新規セッション） |
| 現状把握 | WASD 各キー必要秒長押し |
| 雨漏り | 鉄鱗採集 → 基礎加工台仮組 → 建設投入 → レシピ選択 → 鱗鉄板3生産 → NPC へ3納品 |
| 終了 | `main_rain_leak` **Completed** かつ **宇宙船修理演出が終了**していること。納品完了会話 → **修理演出を最後まで再生**（AutoPlay は待機・ForceSkip しない）→ Completed。次クエスト受注アイコンまで出るが自動プレイはここで停止 |

NPC 納品の正規操作は **手に鱗鉄板を持って DeliveryNpc の `DepositBin` へ右クリック**（`spec/KomayamaCraft_NPCインタラクトと初期納品_詳細仕様.md`）。

### 6.1 エージェント／人手の起動チェックリスト（確定）

| 順 | 内容 |
| --- | --- |
| 1 | `本番リリース用` は OFF |
| 2 | 「チュートリアル自動プレイ」ON |
| 3 | **新規ゲーム**で起動（`KomayamaBootRequest.RequestNewGame`。セーブ続き禁止） |
| 4 | Play。成功ログと §11 の終了アサートを確認 |
| 5 | 失敗時は `[CraftAutoPlay] FAIL:` で即停止。手動倍速は触ってよいが自動化は倍速を変えない |

## 7. 失敗・観測（確定）

| 項目 | 内容 |
| --- | --- |
| 進行不能 | 一定時間（現行 120 秒）観測キーが進まない、必須参照欠落 |
| 失敗時 | ログを出して**即停止** |
| 成功時 | `[CraftAutoPlay] Stopped: delivery complete` のあと **終了アサート通過**をログ（§11） |

## 8. 既存仕様との接点

| 既存 | 自動化での扱い |
| --- | --- |
| 施設上左クリック：ドロップ拾い ＞ メニュー | 疑似クリックも同じ優先 |
| 生産完了は地面ドロップ | 拾い成功／カウンタ増加を観測 |
| NPC 納品 | P0 で実装済み（右クリック `DepositBin`）。**3／3 後は会話・修理待ちでクリックしない** |
| 会話開始 | 先行会話中は待ってから再生。`Already playing` 無視で completed が来ないハングを避ける |
| ゲーム倍速 Debug | 手動設定可。自動化は触らない |
| 会話スキップボタン | **使わない**。送りのみ |

## 11. 常緑ゲート（確定）

P0 は **コンテンツ追加の回帰ゲート**とする。クエスト／会話／フィールド操作／船・狐まわりを触ったら、マージ前に §6.1 で **1 回通す**。

### 11.1 成功定義

| 項目 | 内容 |
| --- | --- |
| 到達 | OP → 現状把握 → 雨漏り初期納品 → 納品完了会話 → **宇宙船修理演出（フル再生）** |
| 停止条件 | `main_rain_leak` が **Completed** かつ `KomayamaShipRepairCinematic.IsPlaying == false` |
| 終了アサート（読み取りのみ） | 船見た目段階 = `StageAfterRainLeak`（`ship_2`）／狐 `DisplayMode != Off`／`IsSuppressedForCinematic == false` |
| 成功ログ例 | `[ShipRepair] AutoPlay is running — playing full cinematic` → `[CraftAutoPlay] PostAssert OK` → `[CraftAutoPlay] Stopped: delivery complete` |
| アサート失敗 | `[CraftAutoPlay] FAIL: postcondition ...` で即停止（成功扱いにしない） |

### 11.2 いつ回すか

| 変更領域 | P0 必須 |
| --- | --- |
| クエスト進行・目標・監視フラグ | Yes |
| 会話 CSV／送り／OP | Yes |
| 採集・建設・施設メニュー・納品 | Yes |
| 宇宙船修理演出・マウス狐表示 | Yes |
| UI 見た目のみ（進行に触れない） | 任意 |

### 11.3 起動の注意（再掲）

- セーブ続き禁止。静的 `StartNewGame` だけでは残存ブート要求でロードに上書きされうる → `RequestNewGame(slot)` を使う
