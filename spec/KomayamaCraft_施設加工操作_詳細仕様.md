# KomayamaCraft 施設加工操作 詳細仕様

## 0. 文書の位置づけ

- 完成した加工施設の**操作・UI・生産ループ・ワールド表示・排出**を定める。
- 建設・仮組・編集は `spec/KomayamaCraft_建設メニュー_詳細仕様.md` が正本。
- 個別レシピ・設備ラインはサプライチェーン／Tier 詳細が正本。
- 保存フィールドは `spec/データ基盤_保存データ契約.md` を参照し、本書で運用を上書きする箇所を明記する。
- 値の書き方：**確定**／**提案**／**現行値**。

---

## 1. 前提

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 対象 | 完成した加工施設（仮組は加工不可） | 確定 |
| 完成直後のレシピ | **未選択（空）**。レシピを選ぶまでクラフト不可 | 確定 |

| 連続生産 | 投入素材がなくなるまで自動連続 | 確定 |

## 2. 左クリック（メニュー）

### 2.0 施設上の左クリック優先

完成施設のコライダー上を左クリックしたときの判定順：

| 優先 | 条件 | 結果 | 区分 |
| --- | --- | --- | --- |
| 1 | クリック位置（または拾い半径内）に拾える地面ドロップがある | **アイテムを拾う**。施設メニューは開かない | 確定 |
| 2 | 上記以外で完成施設をヒット | **施設メニューを開く**（§2.1／§2.2） | 確定 |

拾い対象があったが手持ち満杯などで失敗した場合も、施設メニューへフォールスルーしない（失敗理由を出す）。

### 2.1 メニュー分岐

完成施設を左クリックし、§2.0 でメニューを開くときの画面：

| 状態 | 開く画面 | 区分 |
| --- | --- | --- |
| レシピ未選択 | **レシピ選択メニュー** | 確定 |
| レシピ選択済み・停止中（Idle／素材待ち／燃料待ち） | **素材・生産品画面**（停止理由の表示を含む。例：燃料なし） | 確定 |
| クラフト中（Processing） | **素材・生産品画面** | 確定 |

画面レイアウトの見た目正本は参照 UI（レシピ選択＝3×3＋詳細、素材・生産品＝現状レシピ＋進捗＋排出／レシピ変更）。実装時に同構成へ合わせる。

### 2.1.1 FacilityMenu の開閉（実装）

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| ホスト | `SystemCanvas/FacilityMenu`（`KomayamaFacilityMenuView`） | 確定 |
| 開始時 | ホスト GO は **Active**。表示内容の親 `Content` だけ **非表示** | 確定 |
| 開く | 完成施設クリック → `Open`。必要ならホストを Active にし、`Content` を表示 | 確定 |
| 閉じる | `Content`（およびレシピ／ステータスパネル）を非表示。**ホスト GO は Active のまま** | 確定 |
| 注意 | ホスト全体を非 Active にするとクリックで開けなくなる | 確定 |

### 2.2 レシピ選択メニュー

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 役割 | 施設で使えるレシピを選び、初めてクラフト可能にする | 確定 |
| 選択後 | そのレシピが `selectedRecipeId` になる。条件が揃えば自動生産開始（§4） | 確定 |
| Hierarchy | `FacilityMenu/Content/RecipePanel` | 確定 |
| グリッド | `RecipeGrid`。見た目・配置は **Inspector／Hierarchy で調整**（コードは子スロットを生成・レイアウトしない） | 確定 |
| スロット | `RecipeSlot_0` 等の `Button`（子に `Icon`／`Selected`／`Disebled`）。Hierarchy 上は最大 **9**（3×3）を用意。複製して枠を増やす | 確定 |
| 割当順 | **①解放済み（生産可能）を左上から** → **②未解放**。施設の `SupportedRecipes` 内の相対順は維持 | 確定 |
| 空き枠 | 割り当てるレシピが無いスロットは **非表示**（空の「?」枠は出さない） | 確定 |
| ホバー | スロット上に `Selected` オーバーレイを表示。`Icon` は **成果アイテム画像** | 確定 |
| 未開放 | スロット上に `Disebled`（または `Disabled`）オーバーレイを表示。`Icon` は **未開放用テンプレート画像をそのまま**（差し替えない） | 確定 |
| 見た目テンプレート | `RecipeSlotSelected`／`RecipeSlotDisabled`（実行時は非表示）。子の `Selected`／`Disebled`／`Icon` の Image を差し替えれば次回適用で反映。テンプレート自体はコードが書き換えない | 確定 |
| 詳細 | `RecipeDetailTitle`＝製品名、`RecipeDetailIcon`＝製品アイコン、`RecipeDetailBody`＝製品説明（未記入は空） | 確定 |
| 必要素材 | `IngredientOj`／`IngredientsSlot1`〜`6`。ホバー中レシピの入力のみ（**燃料なし**）。`IngredientsCount` に必要個数（`xN`） | 確定 |
| クリック | 解放済みスロットのみレシピ選択。未開放は詳細プレビューのみ | 確定 |
| 共通枠 | `Content/CloseStatus`・`Content/MenuTitle` を Status と共用 | 確定 |

### 2.3 素材・生産品画面

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 表示 | 選択中レシピ、必要素材の所持／必要、加工時間、進捗、燃料関連**メッセージ**（一覧スロットには燃料を出さない）等 | 確定 |
| 使用素材一覧 | レシピ入力のみ。**燃料は入れない**（燃料はワールド右の燃料メーター §7） | 確定 |
| 表示上限 | **最大 6 種**（それ以上はデータ側で避ける／先頭 6 のみ表示） | 確定 |
| レイアウト | `Layout_1`〜`Layout_6` の **固定見た目を切替**。個数に応じて位置を動的再配置しない。Inspector／Hierarchy で各 Layout を調整する | 確定 |
| **レシピ変更** | レシピ選択メニューへ戻る（切替時の処理は §5） | 確定 |
| **排出** | §6 | 確定 |
| 閉じる | 画面右上の閉じる操作（見た目は参照 UI） | 提案 |

## 3. 投入（右クリック）

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 手段 | 手持ちを**完成施設のコライダー**へ右クリック | 確定 |
| メニューからの投入 | なし | 確定 |
| 振り分け | 手持ちアイテム種別で **入力素材／燃料** を自動判定 | 確定 |
| 単位 | 既存の設備投入規則（受け取れる種類を手持ちから探す。1 個ずつ等）に従う | 確定 |
| 完成直後の長押し | 建設仕様どおり、離して再押下まで生産投入しない | 確定 |
| 燃料アイテム | **蓄電触腕**（`item.volt_jelly`）。浜辺のワールド物体「蓄電クラゲ」から自動ドロップ。供給・配置の詳細は `spec/KomayamaCraft_詳細仕様_指示差分と数値.md` §7.1.1 | 確定 |

燃料を使わない施設では燃料枠への投入は行わない（受け入れ不可）。

## 4. 生産ループ

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 開始 | レシピ選択済みかつ、必要素材（＋燃料を使う施設なら必要燃料）が揃ったら **自動開始**。別ボタンなし | 確定 |
| 消費タイミング | **1 回の生産開始瞬間**に、その回の必要素材と必要燃料を消費する | 確定 |
| 進行中 | ワールド中央に生産物アイコン＋`×` 予定個数＋円形残り時間（§7） | 確定 |
| 完了 | 完成品を地面へドロップ（§8）。内部出力スロットには積まない。**このときレシピ別 EXP を付与**（`spec/KomayamaCraft_経験値レベル_詳細仕様.md`） | 確定 |
| 連続 | 完了後、まだ投入素材等で次の 1 回が始められるなら **自動で次を開始**。投入素材がなくなるまで継続 | 確定 |
| 停止 | 素材不足 → 素材待ち。燃料不足 → 燃料待ち。メニュー上で分かる表示にする。ワールド上の不足アイコンは出さない（§7） | 確定 |
| EXP 無効 | 生産中の破棄（レシピ変更・排出による進行破棄）／施設破壊・撤去で未完了になった回は **EXP なし** | 確定 |

## 5. レシピ変更

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 生産中に変更 | **進行は破棄**。その回で既に消費した素材・燃料は **消滅**（返却しない） | 確定 |
| 未使用の入力素材 | **ドロップ返却**（§8 の起点） | 確定 |
| 燃料 | **施設内に残す**（レシピ変更では出さない） | 確定 |
| 変更後 | 新レシピが選ばれるまで／条件が揃うまで生産しない。揃えば自動開始 | 確定 |

メニュー「排出」（素材排出）の対象と結果：

| 施設状態 | 排出する内容 | 進行中の 1 回 | 区分 |

| 停止中（Idle／素材待ち／燃料待ち） | **未使用の入力素材＋燃料** をドロップ | （なし） | 確定 |
| 生産中（Processing） | **未使用の入力素材のみ** をドロップ。**燃料は残す** | **破棄**（消費済みは消滅） | 確定 |

| 排出後の画面 | レシピ選択メニューを開く | 確定 |
| 排出後の状態 | Idle | 確定 |

ドロップ位置は §8。メニュー内に残さず、常に地面へ出す。

## 7. ワールド上の常時表示

メニューの開閉に依存しない。見た目の正本は参照画像（施設上 HUD）。実装は `KomayamaFacilityWorldOverlay`（プレハブ配下 `FacilityWorldHud`）。

| 表示 | 位置 | いつ出すか | 内容 | 区分 |
| --- | --- | --- | --- | --- |
| **素材** | 施設上側 | **レシピ選択後**は常時。未選択時は出さない | 選択中レシピの入力素材のみ（**燃料なし**）。最大 6。`Layout_1`〜`Layout_6` 固定切替。アイコン上に **投入／必要**（例：`5/2`） | 確定 |
| **生産インジケータ** | 施設中央 | **レシピ選択後**は常時。未選択時は出さない | 成果アイコン＋**予定成果個数を `×N`**（いまの投入在庫から見込める個数。生産中の 1 回分を含む）。外周の**円形リングで残り時間**（生産中のみ減る） | 確定 |
| **燃料メーター** | 施設右（既定）。位置はプレハブで調整可 | 燃料を使う施設では、**レシピ未選択でも常時** | §7.1 | 確定 |
| 素材不足・燃料なし等の不足アイコン | — | **ワールド上には出さない**（メニュー側の文言・状態表示で足りる） | — | 確定 |

燃料を使わない施設では燃料メーターは出さない。

予定成果個数は、投入在庫で何クラフト分できるか（燃料制約がある施設は燃料残も下限）× 1 回あたりの成果個数。生産中なら進行中の 1 回分を加算する。

### 7.1 燃料メーター（本画像）

アセット（`Assets/Sprites/facility/`）：

| 役割 | ファイル | Hierarchy 名 | 区分 |
| --- | --- | --- | --- |
| 背景 | `fuel_bk.png` | `FuelBk` | 確定 |
| 残量バー | `fuel_bar.png` | `FuelFill` | 確定 |
| 枠 | `fuel_枠.png` | `FuelFrame` | 確定 |
| ピクト | `fuel_pict.png` | `FuelPict` | 確定 |

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 残量表示 | `FuelFill` は Image **縦 Fill**（下原点）。`fillAmount = FuelAmount / FuelCapacity`（使用のたび割合で減る） | 確定 |
| ピクト | 残量 **> 0** で点灯、**0 で消灯**（enabled OFF） | 確定 |
| 実行時が触るもの | Fill 量とピクト点灯のみ | 確定 |
| 位置・サイズ・見た目 | **コードで毎フレーム上書きしない**。`FacilityWorldHud/Fuel` 配下をプレハブ／Inspector で調整 | 確定 |
| 自動配置 | `autoPlaceFuelByFootprint` は **既定 OFF**。ON のときのみ足跡右へ再配置 | 確定 |

### 7.2 施設本体スプライト（稼働アニメ）

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| 対象（本段階） | 基礎加工台（`facility.prep_bench`）。仕組みは他設備へ横展開可 | 確定 |
| ベース画像 | ナンバリングなし（例：`facility_基礎加工台.png`）。**ブループリント／未稼働**（Idle・素材待ち・燃料待ち）で使用 | 確定 |

| 実装 | `KomayamaFacilityVisualAnimator`＋プレハブの SpriteRenderer | 確定 |

## 9. 保存契約との関係

| フィールド／状態 | 本書での運用 | 区分 |
| --- | --- | --- |
| `selectedRecipeId` | 空＝未選択。完成直後は空 | 確定 |
| `inputItems` / `fuelItems` / `storedFuelEnergy` | 未消費の内部在庫・燃料として使用 | 確定 |
| `outputItems` | **常に空**。完成品は保存せず地面アイテム側へ出す | 確定 |
| `WaitingForOutput`（状態 4） | **実行時は使用しない**（互換のため列挙値は残す） | 確定 |
| `processingState` / `processingProgress01` | Idle／WaitingForInput／WaitingForFuel／Processing／Paused を使用 | 確定 |

セーブ契約の列挙値の番号・並べ替えは変更しない（`データ基盤_保存データ契約.md`）。
