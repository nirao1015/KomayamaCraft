# M3 Tier 1完成

## 目標

Tier 1の素材、設備、レシピをデータと実行時で揃え、船殻再生鱗と恒星炉の種火まで**生産**できるようにする。宇宙船への組み込みとTier 2解放はM5。

## M2からの申し送り

- 鉄鱗、鉄鱗板、鱗圧延作業台、プロトタイプ保管は既存。再利用し、複製定義を作らない。
- 燃料はM3から本導入する。
- 建設・セーブはM2済み前提。新しい設備も同じ配置・保存経路を使う。

## 完成条件

- 鉄鱗、熱嚢、蓄電クラゲを非致死的に採集できる。
- Tier 1の全レシピがデータから動作する。
- 船殻再生鱗と恒星炉の種火まで生産できる。
- 保存・ロード後もTier 1の生産状態が維持される。
