# M0 基盤設計

## 目標

アイテム、レシピ、設備、資源発生点、解放フラグをデータとして定義し、コードを書き換えずに内容を追加できる基盤を作る。

## 個別タスク

- [x] `TASK-M00-01_永続IDとデータ規約.md`：ID命名、参照方法、廃止・改名規約を定義
- [x] `TASK-M00-02_アイテム定義.md`：素材・中間品・完成品の共通データを実装
- [x] `TASK-M00-03_レシピ定義.md`：入力、出力、設備、時間、解放条件をデータ化
- [x] `TASK-M00-04_設備と資源発生点定義.md`：設備能力と採集対象をデータ化
- [x] `TASK-M00-05_解放条件定義.md`：解放フラグと前提条件をデータ化
- [x] `TASK-M00-06_カタログと検証.md`：重複ID、参照切れ、不正値をEditorで検出
- [x] `TASK-M00-07_保存データ契約.md`：配置・在庫・加工状態を保存可能にするDTOとversion方針を定義

## 完成条件

- データ追加だけで素材、レシピ、設備、資源発生点を増やせる。
- すべての保存対象が安定した永続IDを持つ。
- 不正なデータ参照をゲーム開始前に検出できる。
- M1以降が特定のTier名をコードへ直接埋め込まず実装できる。
