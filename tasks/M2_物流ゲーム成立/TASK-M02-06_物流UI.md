# TASK-M02-06 物流UI

## 目的

手持ち、地面、チェスト、設備の「何がどこに何個あるか」を画面だけで把握できるようにする。

## 参照仕様

- `spec/KomayamaCraft_ゲーム基本仕様.md`

## 依存タスク

- TASK-M02-05

## 作業範囲

- 手持ちの品種、個数、上限を常時表示する。
- 選択中またはカーソル下のチェスト・設備の入出力を表示する。
- 建設モードと編集モードの現在状態、コスト、拒否理由を表示する。
- M1の操作ガイドを、建設と保管を含む文言へ更新する。
- UIは16:9ゲーム領域に収め、ワールド操作へ貫通させない。

## 対象外

- 製品版ビジュアル
- 設定画面
- Ghostの担当表示
- キーボード以外の表記切替

## 完了条件

- [ ] 手持ちと設備内部を見比べて運搬判断できる。
- [ ] 建設不可、コスト不足、満杯、品種不一致の理由が出る。
- [ ] UI上クリックが採集や建設へ貫通しない。

## 確認方法

1. チェストと作業台に異なる数量を入れる。
2. カーソルを乗せて中身が分かること。
3. 建設モードで不可位置の理由が出ること。
