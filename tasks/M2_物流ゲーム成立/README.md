# M2 物流ゲーム成立

## 目標

手持ち容量、チェスト、建設、複数設備、基本セーブを入れ、「素材がどこにあるか」が生産効率に効く状態を作る。

## M1からの申し送り

- 手持ちは1品種スタック済み。M2は複数スロットを足さず、容量を運搬回数が出る値にする。
- ドロップ禁止塗り（`DropBlocker` / `NoDropPaint`）は実装済み。建設不可塗りは別盤面（`PlacementBlocker`）にする。
- 押しのけソルバの広域探索はM2ではやらない。置けない新規品は消滅＋理由表示のままにする。
- 保管設備定義`facility.prototype_storage`と保存DTOはM0済み。M2で実行時とI/Oを載せる。
- 燃料、Ghost、複数スロット手持ち、タイトル遷移は対象外。

## 完成条件

- 手持ち容量によって運搬回数が変化する。
- 複数のチェストと設備を使い分けられる。
- 配置した設備と在庫を保存後に復元できる。
- 共通在庫ではなく、素材の所在が生産効率へ影響する。
