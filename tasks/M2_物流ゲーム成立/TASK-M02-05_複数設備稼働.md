# TASK-M02-05 複数設備稼働

## 目的

2台以上の設備が、互いの内部状態を共有せず同時に動くことを確認する。

## 参照仕様

- `spec/KomayamaCraft_ゲーム基本仕様.md`

## 依存タスク

- TASK-M02-04

## 作業範囲

- 鱗圧延作業台を2台置けるようにする。
- 各作業台が独自の入力・進捗・出力を持つ。
- チェストと作業台を同時に操作できる。
- 一方が満杯でも他方は加工を続けられる。
- 共通在庫や静的な単一台前提を残さない。

## 対象外

- レシピ選択UI
- 燃料
- 自動搬送
- 3台以上のバランス調整

## 完了条件

- [ ] 2台の作業台を同時に加工できる。
- [ ] 片方の完成品を残したまま、もう片方へ投入できる。
- [ ] チェストAの中身を作業台Bだけが使う、という所在の違いが再現できる。

## 確認方法

1. 作業台を2台建設する。
2. それぞれに鉄鱗を入れ、同時に進捗することを確認する。
3. チェスト経由と直投入で、届く作業台が変わることを確認する。
