# M6 Tier 2完成

## 目標

磁角と結晶培養炉を中心とする電装・航法系を完成させ、星図復元核を宇宙船へ組み込めるようにする。

## 前提

- M5でTier 2地域と設計図が開いていること。
- Tier 1部品は再利用する。新規定義の複製をしない。
- 星図復元核の組み込みでTier 3解放条件を満たす。解放評価はM5の基盤を使う。
