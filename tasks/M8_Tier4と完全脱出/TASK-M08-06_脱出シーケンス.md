# TASK-M08-06 脱出シーケンス

## 目的

プレイヤー操作で離陸、惑星圏離脱、エンディングへ進む。

## 依存タスク

- TASK-M08-05

## 作業範囲

- 脱出確認、シーケンス、エンディング表示を実装する。
- 演出は仮でも、中断と完了の状態は残す。
- 本編理解に配信知識を要求しない。

## 対象外

- 製品品質の映像
- Steam実績発火（M10/M11）

## 完了条件

- [ ] 操作でエンディングまで到達できる。
- [ ] 未復旧では開始できない。
- [ ] シーケンス中にセーブが壊れない。

## 確認方法

1. 復旧済み状態から脱出する。
2. エンディング後の状態遷移を確認する。
