# TASK-M04-05 燃料補給

## 目的

燃料アイテムを保管先から不足設備へ運ぶ。

## 依存タスク

- TASK-M04-04

## 作業範囲

- 燃料不足の設備を対象にする。
- 供給元は、その燃料を持つチェスト。
- 1個ずつ運び、設備の燃料容量を超えない。
- 手作業の燃料投入も残す。

## 対象外

- 新しい燃料種の追加（既存Tier 1燃料を使う）
- 電力網などの別資源

## 完了条件

- [ ] 燃料切れ設備が自動で再稼働する。
- [ ] 供給元が無いと停止理由を出す。
- [ ] プレイヤー投入と二重消費しない。

## 確認方法

1. 燃料入りチェストと空の燃料設備を置く。
2. Ghostを稼働させ、設備が加工を再開することを確認する。
