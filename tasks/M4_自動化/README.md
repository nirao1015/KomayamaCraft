# M4 自動化

## 目標

手作業だった採集、回収、搬送、燃料補給を個別に自動化し、自動化自体を進行報酬として成立させる。

## 前提

- M3まで手作業で全工程ができること。自動化は代替であり、手作業を消さない。
- ドロップ失敗の自動吸入は、Ghostが対応チェストへ運ぶ形でのみ扱う。広域リパックはしない。

## 個別タスク

- [ ] `TASK-M04-01_自動作業共通基盤.md`：待機、対象選択、移動、作業、復帰
- [ ] `TASK-M04-02_Ghost配置.md`：拠点、配置、稼働
- [ ] `TASK-M04-03_Ghost回収配送.md`：地面品から対応チェストへ
- [ ] `TASK-M04-04_自動採集.md`：指定資源の自動産出
- [ ] `TASK-M04-05_燃料補給.md`：燃料取得と不足設備への補給
- [ ] `TASK-M04-06_競合と停止理由.md`：競合、満杯、経路なし、燃料なし
- [ ] `TASK-M04-07_自動化UI.md`：担当、運搬物、待機理由

## 完成条件

- 採集、回収、チェスト配送、燃料補給を個別に自動化できる。
- 自動化されていない工程は手作業で補える。
- 複数作業者が同じ対象を選んでもアイテムが重複しない。
- 停止中の理由をプレイヤーが確認できる。
