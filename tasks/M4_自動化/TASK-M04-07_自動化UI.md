# TASK-M04-07 自動化UI

## 目的

各Ghostの担当、運搬中、停止理由をプレイヤーが見られるようにする。

## 依存タスク

- TASK-M04-06

## 作業範囲

- 選択中Ghostの状態、運搬物、停止理由を表示する。
- 稼働切替をUIまたはクリックで行う。
- 16:9領域に収め、ワールド操作へ貫通させない。

## 対象外

- 製品デザイン
- 詳細な優先度エディタ

## 完了条件

- [ ] 停止中のGhostを見て理由が分かる。
- [ ] 運搬中の品種が見える。
- [ ] UI操作が採集へ貫通しない。

## 確認方法

1. 満杯停止のGhostを選択する。
2. 理由表示を確認する。
3. 再稼働できることを確認する。
