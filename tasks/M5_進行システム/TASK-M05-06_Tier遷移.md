# TASK-M05-06 Tier遷移

## 目的

Tier 1修復の完了でTier 2を解放し、次の目標が見えるようにする。

## 依存タスク

- TASK-M05-05

## 作業範囲

- Tier 1完了判定をUnlockデータで行う。
- Tier 2地域、設計図、必要ならGhost強化を報酬として出す。
- 完了演出は仮のメッセージでよい。製品演出はM11。
- 既存のTier 1生産は継続できる。

## 対象外

- Tier 2素材の本実装
- エンディング

## 完了条件

- [ ] 両修復部品の投入後にTier 2が解放される。
- [ ] 片側だけ投入しても解放されない。
- [ ] Tier 1設備は使い続けられる。

## 確認方法

1. 船に両方投入する。
2. Tier 2区画または設計図が開くことを確認する。
3. 鉄鱗ラインが残っていることを確認する。
