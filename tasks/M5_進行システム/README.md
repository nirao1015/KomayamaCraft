# M5 進行システム

## 目標

宇宙船への修復部品投入、地域解放、設計図、スキル、Tier解放を接続し、Tier 1生産物でTier 2へ進める。

## 前提

- M3で修復部品は生産済み。M5で船に組み込む。
- 解放条件データはM0済み。M5で評価と報酬適用を実装する。

## 個別タスク

- [ ] `TASK-M05-01_宇宙船復旧状態.md`：要求、投入、段階
- [ ] `TASK-M05-02_地域解放.md`：通行、表示、採集、設備
- [ ] `TASK-M05-03_設計図.md`：取得済み設備だけを建設候補へ
- [ ] `TASK-M05-04_経験値とスキル.md`：経験値、レベル、ポイント
- [ ] `TASK-M05-05_解放条件評価.md`：複数条件と報酬
- [ ] `TASK-M05-06_Tier遷移.md`：Tier 1完了とTier 2解放
- [ ] `TASK-M05-07_進行保存.md`：修復、地域、設計図、スキル、Tier

## 完成条件

- Tier 1修復部品の投入によってTier 2が解放される。
- 地域、設備、レシピ、自動化がデータ上の条件で解放される。
- 所持、納品、報告、解放済みを別状態として管理できる。
- 進行状態を保存・復元できる。
