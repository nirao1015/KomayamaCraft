# TASK-M01-05 設備投入と加工

## 目的

鉄鱗を鱗圧延作業台へ投入し、定義レシピで鉄鱗板へ加工する。

## 依存タスク

- TASK-M01-04

## 作業範囲

- 設備右クリック/長押しで手持ち素材を1個ずつ投入する。
- 材料が揃えば自動で加工を開始する。
- 加工時間、入出力はRecipeDefinitionに従う。
- M1では燃料を要求しない。

## 対象外

- レシピ選択、複数入力、燃料補給、自動物流

## 完了条件

- [x] 鉄鱗だけを投入できる。
- [x] 必要数が揃うと1.5秒加工する。
- [x] 加工完了後に鉄鱗板を出力バッファへ保持する。

## 確認方法

1. 鉄鱗を持って作業台を右クリックする。
2. 進捗後に完成品待機表示を確認する。
