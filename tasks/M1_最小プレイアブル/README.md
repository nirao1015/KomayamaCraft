# M1 最小プレイアブル

## 目標

採集から加工品回収まで、Tier 1の1レシピを最初から最後まで操作できる縦切りを作る。

## 個別タスク

- [x] `TASK-M01-01_新作フィールドシーン.md`：カメラ、入力、16:9表示、検証用フィールドを作成
- [x] `TASK-M01-02_資源採集.md`：資源発生点へのクリックと採集進行を実装
- [x] `TASK-M01-03_地面ドロップ.md`：`DropArea`内への生成と`DroppedItem`管理を実装
- [x] `TASK-M01-04_回収と手持ち.md`：ドロップ品を拾って保持する最小機能を実装
- [x] `TASK-M01-05_設備投入と加工.md`：素材投入、加工時間、完成品生成を実装
- [x] `TASK-M01-06_完成品回収.md`：設備出力から手持ちへ回収できるようにする
- [x] `TASK-M01-07_最小機能UI.md`：数量、進行、実行不可理由を表示

## 完成条件

- 1種類の資源を採集できる。
- 地面へ出た素材を拾える。
- 素材を1台の設備へ投入できる。
- 1レシピを加工し、完成品を回収できる。
- 操作不能や材料不足の理由が画面で分かる。

## 実装・検証結果

- 100個連続散布: 境界外0、重なり0、拒否0。
- M1縦切り: 鉄鱗採集→回収→投入→加工→鉄鱗板回収をPlay Modeで確認済み。
- `Tools/KomayamaCraft/Game Data/Validate All`: 0 errors。
- Unity Console: 最終確認時 Error/Warning 0件。
