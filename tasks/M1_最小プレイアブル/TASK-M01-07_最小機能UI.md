# TASK-M01-07 最小機能UI

## 目的

M1の現在状態、操作、失敗理由を画面だけで把握できるようにする。

## 依存タスク

- TASK-M01-02〜06

## 作業範囲

- 操作ガイド、手持ち、採集、設備入力、加工進捗、出力を表示する。
- 操作不能理由を一時メッセージとSEで通知する。
- 16:9ゲーム領域にUIを収める。

## 対象外

- 製品版デザイン、設定画面、キーボード以外の表記切替

## 完了条件

- [x] M1ループに必要な状態が常時確認できる。
- [x] DropArea外、満杯、品種不一致などの理由が表示される。
- [x] UI上操作がワールド操作へ貫通しない。

## 確認方法

1. 採集から完成品回収まで操作する。
2. 成功状態と拒否理由の表示を確認する。
