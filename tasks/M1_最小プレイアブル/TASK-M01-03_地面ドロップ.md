# TASK-M01-03 地面ドロップ

## 目的

DropArea内だけで、重ならない地面アイテム配置を成立させる。

## 依存タスク

- TASK-M01-02

## 作業範囲

- 産出元からInspector指定のランダム円形範囲へ配置する。
- 各ドロップ品に中心点とInspector指定の円形存在範囲を持たせる。
- 存在範囲が重なった品だけを中心間の接触方向へ押し、接触先へ連鎖させる。
- 押しのけられた品は0.15秒でEase-out移動し、移動中は回収不可にする。
- 無関係な既存品を含む全体再配置は行わない。
- 採集品は産出点から確定した中心点へ放物線状に飛び出して着地する。
- 禁止領域は0.5単位の`NoDropPaint` Tilemapへペイントして編集可能にする。建設用塗りとは分ける。
- 全候補位置を計算してから一括反映する。
- 解決不能時は新規品だけを消滅させ、既存配置を変えない。
- 手動ドロップもDropArea外では拒否する。

## 対象外

- Rigidbodyによる物理散乱、個数上限

## 完了条件

- [x] アイテムがDropArea外へ出ない。
- [x] アイテム同士が指定中心間距離より近づかない。
- [x] 押しのけが接触したアイテムだけへ連鎖する。
- [x] 押しのけ移動が補間表示され、瞬間移動しない。
- [x] 採集品が産出点から山なりに着地する。
- [x] Tile Paletteから禁止領域を描画・消去できる。
- [x] 満杯時も既存品の位置と個数を壊さない。

## 確認方法

1. 鉄鱗を連続産出する。
2. 内側から外側へ広がり、重ならないことを確認する。
3. `Window > 2D > Tile Palette`で`NoDropPaint`を開き、Scene Viewへ塗ってドロップできないことを確認する。
4. 塗った範囲に設備が置けなくなる、という副作用がないことを確認する。

## 編集手順

1. `KomayamaCraft > ドロップ禁止を塗る`を実行する。
2. 先に`Shift+ドラッグ`か広めブラシ（`3`）で広範囲を塗る。
3. `1`で1マスに切り替え、左クリックで足す／右クリックで消して縁を整える。
4. 通常のGame Viewでは塗りは見えない。デバッグの`showNoDropPaint`がオンならプレイ中だけ見える。Rebuildしても既存の塗りは引き継ぐ。
