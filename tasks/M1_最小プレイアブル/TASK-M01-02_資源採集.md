# TASK-M01-02 資源採集

## 目的

鉄鱗獣を操作して、鉄鱗を非致死的に採集できるようにする。

## 依存タスク

- TASK-M01-01

## 作業範囲

- 左クリックした瞬間に1回採集し、連続クリックも制限しない。
- 左ボタン長押し中は初期値0.5秒の間隔で連続採集する。
- 長押し採集間隔は将来のアップグレードから短縮できる構造にする。
- 定義データの産出物・産出数を利用する。

## 対象外

- 戦闘、HP、原生生物の死亡

## 完了条件

- [x] クリックしたフレームで定義どおり鉄鱗が産出される。
- [x] 連続クリックの各入力で1回ずつ産出される。
- [x] 長押し中は0.5秒間隔で産出される。
- [x] 長押し間隔を実行時に短縮できる。

## 確認方法

1. 鉄鱗獣を左クリックする。
2. 同じフレームで鉄鱗が地面へ生成されることを確認する。
3. 連打と長押しを行い、それぞれの産出頻度を確認する。
