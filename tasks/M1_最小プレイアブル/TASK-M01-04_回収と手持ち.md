# TASK-M01-04 回収と手持ち

## 目的

地面の鉄鱗を拾い、カーソルで1品種スタックとして保持する。

## 依存タスク

- TASK-M01-03

## 作業範囲

- 左クリックで地面アイテムを1個ずつ回収する。
- 左ボタンを押したままカーソルを動かし、アイテム判定範囲へ入った場合も即時回収する。
- 手持ちは1品種のみ、ItemDefinitionの最大スタックを上限とする。
- 右クリック/長押しで1個ずつDropArea内へ戻す。
- 手持ち品種と個数をカーソル付近とHUDへ表示する。

## 対象外

- 複数スロットInventory、チェスト、重量

## 完了条件

- [x] 同品種を上限まで回収できる。
- [x] 左ボタンを押したまま複数のドロップ品をなぞって回収できる。
- [x] 異品種または満杯時は回収せず理由を表示する。
- [x] DropArea外への手動ドロップを拒否する。

## 確認方法

1. 鉄鱗を左クリックで拾う。
2. 地面を右クリックして1個ずつ戻す。
