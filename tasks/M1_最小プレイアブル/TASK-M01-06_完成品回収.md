# TASK-M01-06 完成品回収

## 目的

設備に待機した鉄鱗板を明示操作で手持ちへ回収する。

## 依存タスク

- TASK-M01-05

## 作業範囲

- 設備左クリック/長押しで完成品を1個ずつ回収する。
- 手持ち品種不一致・満杯・完成品なしを拒否する。
- 出力が空になった後、次の投入済み素材を加工可能にする。

## 対象外

- 地面への自動排出、搬送設備

## 完了条件

- [x] 鉄鱗板を手持ちへ回収できる。
- [x] 回収不能時に既存出力を失わない。
- [x] 回収後に次の加工へ遷移できる。

## 確認方法

1. 加工完了後の作業台を左クリックする。
2. 手持ちが鉄鱗板になることを確認する。
