# KomayamaCraft 開発タスク

## 運用

- 新作タスクはマイルストーン別フォルダへ置く。
- 個別タスクのファイル名は`TASK-Mxx-nn_短い名称.md`とする。
- 1ファイルは、原則として単独で実装・確認できる大きさにする。
- タスク開始前に依存タスクが完了していることを確認する。
- 完了条件をすべて確認してからタスクを完了扱いにする。
- 仕様変更が必要になった場合は、実装より先に`spec/`を更新する。
- 既存の`tasks/TASK-*.md`は旧作資料として扱い、新作タスクと混在させない。

個別タスクの新規作成には`tasks/TASK_TEMPLATE.md`を使用する。

## マイルストーン

1. `M0_基盤設計`：データ基盤、永続ID、検証、保存形式
2. `M1_最小プレイアブル`：採集から加工品回収までの縦切り
3. `M2_物流ゲーム成立`：手持ち、保管、建設、基本セーブ
4. `M3_Tier1完成`：Tier 1の素材、設備、全レシピ
5. `M4_自動化`：自動採集、燃料補給、搬送
6. `M5_進行システム`：修復、地域、設計図、スキル、Tier解放
7. `M6_Tier2完成`：電装・航法系生産ライン
8. `M7_Tier3完成`：離陸・慣性制御系生産ライン
9. `M8_Tier4と完全脱出`：恒星間航行能力とエンディング
10. `M9_通しプレイ品質`：チュートリアル、保存互換性、通し確認
11. `M10_周辺コンテンツ`：契約、通貨、探索、祝福、実績
12. `M11_製品版仕上げ`：調整、演出、Steam対応、製品品質

各フォルダの`README.md`をマイルストーンの親タスクとし、そこから個別タスクへ分割する。
M2以降の個別ファイルは作成済み。実装開始前に、そのタスクの`実装メモ`と参照仕様を確認する。
